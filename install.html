    설치 방법How to installインストール方法

    내려받은 운영체제에 맞춰 아래 순서대로 설치하세요. 세헤라자드는 구독료 없는 무료 앱으로 계정이나 이메일을 묻지 않으며, 모든 대화와 기억을 바깥으로 보내지 않고 내 컴퓨터의 평문 파일에만 남깁니다. 어떤 운영체제에서든 새 버전이 나오면 앱 안에서 바로 업데이트할 수 있습니다.

    Follow the steps below for your platform. Scheherazade is free with no subscription, asks for no account or email, keeps every memory in plain files on your disk with zero telemetry, and updates inside the app on every platform.

    お使いの OS に合わせて、下の手順に沿ってインストールしてください。サブスクなしの無料アプリで、アカウントやメールアドレスの登録は不要です。すべての会話と記憶は外部へ送信されず手元の平文ファイルに残り、どの OS でもアプリ内からそのままアップデートできます。

    Mac

    Apple 실리콘(M 시리즈) Mac용 설치 파일입니다. CHOAM Co., Ltd.의 Apple Developer ID 서명과 Apple 공증(notarized)을 마친 공식 배포본입니다.

    1. dmg 파일 열기

      내려받은 Scheherazade-버전-arm64.dmg 파일을 더블클릭해 여세요.

    2. 응용 프로그램 폴더로 옮기기

      열린 창에서 Scheherazade 아이콘을 응용 프로그램(Applications) 폴더로 끌어다 놓으세요.

    3. 앱 실행하기

      응용 프로그램 폴더에서 Scheherazade를 여세요. Apple 공증을 마친 앱이라 터미널 명령을 따로 칠 필요 없이 바로 실행됩니다.

    새 버전이 나오면 앱 안의 업데이트 배너에서 내려받는 과정을 확인하고 지금 재시작만 누르면 됩니다. 쓰던 설정과 기억, 멀티 프로필은 그대로 이어집니다.

    Windows

    64비트(x64) Windows용 설치 파일이며, CHOAM Co., Ltd.의 상용 Authenticode 코드 서명이 들어 있습니다.

    1. 설치 파일 실행

      내려받은 Scheherazade-Setup-버전.exe를 실행하세요.

    2. 앱 열기

      설치가 끝나면 시작 메뉴나 바탕화면에서 Scheherazade를 여세요.

    • 새 버전이 막 올라온 직후에는 평판이 쌓이기 전이라 간혹 Windows SmartScreen 창이 뜰 수 있습니다. 공식 배포처(choam.studio 또는 GitHub CHOAM-CO/scheherazade-releases)에서 받은 파일인지, 게시자가 CHOAM Co., Ltd.로 표시되는지 확인한 뒤 실행하세요.

    새 버전이 나오면 앱 안의 업데이트 배너에서 받아 지금 재시작 한 번으로 업데이트할 수 있습니다.

    Windows 포터블 (USB)

    설치하지 않고 NTFS 형식 USB에 담아 다니며 쓰는 Windows 포터블 버전(CHOAM Co., Ltd. 코드 서명 완료)입니다. 데스크톱 세헤라자드에서 쓰던 기억을 그대로 옮겨 담아 다른 Windows PC에서도 이어 쓸 수 있고, 공유 PC에서는 PIN 잠금으로 안전하게 지킬 수 있습니다.

    USB 준비

    NTFS 형식
    필수exFAT이나 FAT32로 된 USB에서는 NTFS 포맷 안내만 띄우고 종료됩니다.
    용량 4GB 이상
    최소압축을 푼 앱이 약 0.7GB를 차지하며, 대화가 쌓일수록 기억 파일이 조금씩 늘어납니다.
    USB 3.0 이상
    권장내부 파일 수가 많아 빠른 USB일수록 압축을 풀고 처음 여는 시간이 짧아집니다.

    포맷하면 USB 안에 있던 파일이 모두 지워집니다. 필요한 파일은 꼭 먼저 다른 곳에 옮겨 두세요.

    1. USB 파일 시스템 확인

      파일 탐색기에서 USB를 오른쪽 클릭해 [속성]을 열고 파일 시스템이 NTFS인지 확인하세요. 아니라면 [포맷]에서 NTFS로 맞추세요.

    2. 폴더에 압축 풀기

      USB 안에 Scheherazade 같은 새 폴더를 만들고 Scheherazade-Portable-버전-win-x64.zip의 압축을 모두 푸세요. 압축을 풀지 않고 ZIP 창 안에서 바로 실행하면 안 됩니다.

    3. 실행 후 PIN·기억 이어받기

      압축을 푼 폴더에서 Scheherazade.exe를 실행하세요. 필요하면 PIN 잠금을 켜거나 데스크톱에 있던 기억을 가져올 수 있습니다.

    4. data 폴더 함께 두기

      처음 실행할 때 같은 자리에 생기는 data 폴더에 기억과 설정, 프로필이 모두 담깁니다. Scheherazade.exe와 늘 같은 폴더에 함께 두세요.

    • USB를 뽑기 전에는 먼저 Scheherazade를 닫고 작업 표시줄의 ‘하드웨어 안전하게 제거’를 눌러 주세요.
    • 여러 사람이 쓰는 PC에서는 앱 설정에서 PIN 잠금을 켜 두고, USB를 잃어버리지 않도록 챙겨 주세요.
    • 새 버전 직후 SmartScreen 안내 창이 뜨면 공식 배포처에서 받은 파일인지와 서명자(CHOAM Co., Ltd.)를 확인한 뒤 실행하세요.
    • 포터블 버전도 앱 안의 업데이트 배너에서 새 버전을 받아 지금 재시작으로 업데이트됩니다. data 폴더의 기억은 그대로 남습니다.

    Linux

    x86_64(64비트 Intel·AMD) Linux용 AppImage 파일입니다.

    1. 실행 권한 주기

      내려받은 Scheherazade-버전-x86_64.AppImage 파일에 실행 권한을 주세요. 파일 관리자의 속성 창에서 켜거나 터미널에서 아래 명령을 실행하면 됩니다.

      chmod +x Scheherazade-*-x86_64.AppImage

    2. 앱 열기

      파일을 더블클릭하거나 터미널에서 실행하세요.

      ./Scheherazade-*-x86_64.AppImage

    Linux(AppImage) 버전도 새 버전이 나오면 앱 안의 업데이트 배너에서 받아 지금 재시작만 누르면 업데이트됩니다.

    처음 켜면 · 약속

    앱을 처음 열면 대화에 쓸 두뇌부터 연결하세요. 이미 구독 중인 Claude, ChatGPT, Google Antigravity(agy / Gemini)는 물론 로컬·클라우드 Ollama도 바로 이어집니다. OpenAI, Anthropic, OpenRouter, DeepSeek, Google, xAI, Groq API 키는 붙여 넣기만 하면 알아서 가려냅니다.

    기억 폴더와 봇을 완전히 나눈 여러 창을 동시에 띄우는 멀티 프로필, Discord·Slack·Telegram 및 음성 통화, 내장 컴퓨터 제어(agent-desktop), 그리고 초암 정본 Seoul을 비롯한 다섯 가지 하우스 테마를 바로 쓸 수 있습니다.

    세헤라자드는 구독료 없는 무료 앱이며, 계정을 만들거나 이메일을 적을 필요가 없습니다. 나눈 대화와 기억은 바깥 서버로 보내지 않고 오직 내 컴퓨터의 평문 파일에만 남깁니다.

    Mac

    For Apple silicon (M series) Macs, signed with an Apple Developer ID (CHOAM Co., Ltd.) and notarized by Apple.

    1. Open the dmg

      Double-click the downloaded Scheherazade-version-arm64.dmg.

    2. Move to Applications

      Drag Scheherazade into the Applications folder in the window that opens.

    3. Open the app

      Launch Scheherazade from Applications. Because the build is signed and notarized by Apple, macOS opens it straight away without any terminal steps.

    When a new release arrives, watch it download in the in-app banner and click Restart now. Your settings, memory, and profiles stay right where they are.

    Windows

    64-bit (x64) Windows installer signed with a commercial Authenticode certificate issued to CHOAM Co., Ltd.

    1. Run the installer

      Open the downloaded Scheherazade-Setup-version.exe.

    2. Open the app

      Once setup finishes, launch Scheherazade from the Start menu or desktop shortcut.

    • Right after a brand-new release goes live, Windows SmartScreen may appear briefly before download reputation catches up. Check that the file came from choam.studio or CHOAM-CO/scheherazade-releases on GitHub and shows CHOAM Co., Ltd. as the publisher, then run it.

    New releases download inside the app with a progress banner; click Restart now to update.

    Windows portable (USB)

    A code-signed (CHOAM Co., Ltd.) Windows build that runs straight off an NTFS USB drive without installing. Bring your desktop Scheherazade memory along to another Windows PC, and lock it behind a PIN on shared machines.

    Prepare the USB drive

    NTFS format
    RequiredOn exFAT or FAT32 drives, the app asks you to format as NTFS and closes.
    4 GB or more
    MinimumThe extracted app takes about 0.7 GB, and your memory folder grows gradually over time.
    USB 3.0 or faster
    RecommendedFaster flash storage makes extraction and the first launch noticeably quicker.

    Formatting erases everything on the drive. Back up any files you want to keep first.

    1. Check for NTFS

      Right-click the USB drive in File Explorer, open Properties, and confirm File system says NTFS (otherwise format it as NTFS).

    2. Extract the ZIP

      Create a folder such as Scheherazade on the drive and extract all of Scheherazade-Portable-version-win-x64.zip into it. Don’t run the app from inside the unextracted ZIP window.

    3. Launch & set up PIN or memory handoff

      Run Scheherazade.exe from that folder. Turn on PIN lock if you use shared PCs, or bring over memory from your desktop install.

    4. Keep the data folder alongside it

      First launch creates a data folder next to Scheherazade.exe for your memory, profiles, and settings. Leave them in the same folder.

    • Quit Scheherazade and use Safely Remove Hardware in the taskbar before pulling the drive out.
    • Turn on PIN lock whenever you carry the drive onto shared PCs, and take care not to misplace the drive itself.
    • If SmartScreen appears briefly right after a new release, confirm the official source and the CHOAM Co., Ltd. signature before running.
    • The portable build updates inside the app too: click Restart now when the download finishes. Your data folder stays intact.

    Linux

    An AppImage for x86_64 (64-bit Intel or AMD) Linux.

    1. Make it executable

      Allow executing Scheherazade-version-x86_64.AppImage in your file manager’s properties, or run:

      chmod +x Scheherazade-*-x86_64.AppImage

    2. Run it

      Double-click the file or start it from a terminal:

      ./Scheherazade-*-x86_64.AppImage

    The Linux AppImage updates inside the app as well: once the banner finishes downloading, click Restart now.

    Mac

    Apple シリコン（M シリーズ）搭載 Mac 専用です。CHOAM Co., Ltd. の Apple Developer ID 署名と Apple 公証（notarized）を済ませた公式ビルドです。

    1. dmg を開く

      ダウンロードした Scheherazade-バージョン-arm64.dmg をダブルクリックして開きます。

    2. 「アプリケーション」へ移す

      開いたウインドウで、Scheherazade のアイコンを「アプリケーション」フォルダへドラッグします。

    3. アプリを開く

      「アプリケーション」フォルダから Scheherazade を開きます。Apple 公証済みのため、ターミナル操作なしでそのまま起動します。

    新しいバージョンが出たら、アプリ内のバナーでダウンロードを確認し、今すぐ再起動を押すだけで更新できます。設定や記憶、プロファイルはそのまま引き継がれます。

    Windows

    64 ビット（x64）版 Windows 用インストーラーです。CHOAM Co., Ltd. の商用 Authenticode コード署名が入っています。

    1. インストーラーを実行

      ダウンロードした Scheherazade-Setup-バージョン.exe を開きます。

    2. アプリを開く

      インストールが終わったら、スタートメニューまたはデスクトップから Scheherazade を起動します。

    • 公開直後でダウンロード実績が貯まる前のあいだ、まれに Windows SmartScreen が出ることがあります。公式配布元（choam.studio または GitHub の CHOAM-CO/scheherazade-releases）から入手したファイルであることと、発行元が CHOAM Co., Ltd. であることを確かめてから実行してください。

    新しいバージョンはアプリ内のバナーからダウンロードされ、今すぐ再起動ひとつで更新されます。

    Windows ポータブル（USB）

    インストールせずに NTFS 形式の USB メモリからそのまま動かせる Windows ポータブル版（CHOAM Co., Ltd. コード署名済み）です。デスクトップ版の記憶を引き継いで別の Windows PC でも続きから使え、共有 PC では PIN ロックで守れます。

    USB メモリの準備

    NTFS 形式
    必須exFAT や FAT32 の USB では、NTFS フォーマットの案内を出して終了します。
    容量 4GB 以上
    最低展開したアプリ本体が約 0.7GB あり、使うほど記憶ファイルが少しずつ増えていきます。
    USB 3.0 以上
    推奨ファイル数が多いため、高速な USB メモリほど展開と初回起動が速くなります。

    フォーマットすると USB 内のファイルはすべて消えます。残したいデータは先に別の場所へ移してください。

    1. USB の形式を確かめる

      エクスプローラーで USB を右クリックして [プロパティ] を開き、ファイルシステムが NTFS になっているか確認します（違う場合は NTFS でフォーマットします）。

    2. フォルダへ展開する

      USB 内に Scheherazade などのフォルダを作り、Scheherazade-Portable-バージョン-win-x64.zip の中身をすべて展開します。展開前の ZIP ウインドウからそのまま起動しないでください。

    3. 起動して PIN や記憶引き継ぎを設定

      展開したフォルダの Scheherazade.exe を開きます。必要に応じて PIN ロックやデスクトップ版からの記憶引き継ぎを設定できます。

    4. data フォルダを一緒に置く

      初回起動時に同じ場所へ作られる data フォルダに、記憶・設定・プロファイルがすべて入ります。Scheherazade.exe と同じフォルダに置いたままにしてください。

    • USB を抜くときは、先に Scheherazade を終了してからタスクバーの「ハードウェアを安全に取り外す」を使ってください。
    • 共有 PC で使うときは設定から PIN ロックをオンにし、USB メモリ自体の置き忘れにもお気をつけください。
    • 公開直後に SmartScreen が出た場合は、公式配布元と署名者（CHOAM Co., Ltd.）を確認してから実行してください。
    • ポータブル版もアプリ内のバナーから今すぐ再起動で更新でき、data フォルダの記憶はそのまま残ります。

    Linux

    x86_64（64 ビット Intel・AMD）Linux 用の AppImage ファイルです。

    1. 実行権限を付ける

      ダウンロードした Scheherazade-バージョン-x86_64.AppImage に、ファイルマネージャーのプロパティかターミナルから実行権限を付けます。

      chmod +x Scheherazade-*-x86_64.AppImage

    2. 起動する

      ファイルをダブルクリックするか、ターミナルから起動します。

      ./Scheherazade-*-x86_64.AppImage

    Linux（AppImage）版も、アプリ内のバナーでダウンロードが終わったら今すぐ再起動を押すだけで更新できます。

    初めて開いたら・約束

    最初に開いたら、設定画面で会話に使う頭脳を繋いでください。契約中の Claude・ChatGPT・Google Antigravity（agy / Gemini）のサブスクや、ローカル／クラウドの Ollama、各種 API キー（OpenAI、Anthropic、OpenRouter、DeepSeek、Google、xAI、Groq を自動判別）をそのまま選べます。

    記憶フォルダと Bot を分けて複数ウインドウを並べられるマルチプロファイル、Discord・Slack・Telegram・音声コールモード、内蔵の PC 操作（agent-desktop）、そして正本テーマ Seoul を含む5つのハウステーマをすぐ使えます。

    Scheherazade はサブスクなしの無料アプリで、アカウント登録もメールアドレスの入力も求めません。やり取りした会話と記憶は外部へ送られず、すべて手元の PC に平文ファイルとして残ります。
