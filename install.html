    설치 방법How to installインストール方法

    받은 파일에 맞는 항목의 순서대로 설치하세요. 업데이트 방법은 각 항목 끝에 있습니다.

    Follow the steps for the file you downloaded. How to update is at the end of each section.

    ダウンロードしたファイルに合った手順に従ってください。アップデートの方法は各項目の最後にあります。

    Mac

    Apple 실리콘(M 시리즈) Mac 전용입니다. Intel Mac용 파일은 아직 없습니다.

    1. dmg 열기

      받은 Scheherazade-버전-arm64.dmg를 더블클릭해서 여세요.

    2. 응용 프로그램 폴더로 옮기기

      열린 창에서 Scheherazade 아이콘을 응용 프로그램(Applications) 폴더로 끌어다 놓으세요.

    3. 앱 열기

      응용 프로그램 폴더에서 Scheherazade를 여세요.

    ‘손상되었기 때문에 열 수 없습니다’가 뜨면

    아직 Apple 개발자 서명과 공증이 없어서, 인터넷에서 받은 이 앱을 macOS가 막는 경우입니다.

    이 메시지가 뜰 때만, 먼저 dmg를 choam.studio나 GitHub의 CHOAM-CO/scheherazade-releases에서 받았는지 확인하세요.

    다른 곳에서 받은 파일이라면 실행하지 말고 삭제하세요.

    출처가 맞다면 터미널을 열고 아래 한 줄을 실행한 뒤, 앱을 다시 열어 주세요.

    xattr -dr com.apple.quarantine /Applications/Scheherazade.app

    이 명령은 Scheherazade 앱과 그 안의 파일에서 macOS 격리 속성(com.apple.quarantine)만 지웁니다. 다른 앱이나 Mac 전체의 보안 설정은 바꾸지 않습니다.

    앱을 다른 위치에 두었다면 경로를 그 위치로 바꿔서 실행하세요. 새로 받은 파일로 다시 설치하면 이 과정이 또 필요할 수 있습니다.

    업데이트는 자동으로 설치되지 않습니다. 새 버전 알림이 오면 새 dmg를 받아 같은 방법으로 앱을 교체하세요. 설정과 기억, 프로필은 그대로 남습니다.

    Windows

    64비트(x64) Windows용 설치 파일입니다.

    1. 설치 파일 실행

      받은 Scheherazade-Setup-버전.exe를 실행하세요.

    2. 출처 확인 후 실행

      ‘Windows의 PC 보호’ 창이 뜨면, 먼저 파일을 choam.studio나 GitHub의 CHOAM-CO/scheherazade-releases에서 받았는지, 파일 이름이 위와 같은지 확인하세요.

      맞다면 [추가 정보]를 누른 뒤 [실행]을 누르세요. 아직 코드 서명이 없어서 게시자가 ‘알 수 없음’으로 표시됩니다.

      다른 곳에서 받은 파일이라면 실행하지 말고 삭제하세요.

    3. 앱 열기

      설치가 끝나면 시작 메뉴에서 Scheherazade를 여세요.

    업데이트는 앱이 알아서 받아 설치합니다.

    Windows 포터블 (USB)

    설치 없이 USB에 넣어 다니며 쓰는 Windows용 버전입니다. 기억과 설정, 프로필, 키가 USB 안 폴더에 저장되므로, 다른 Windows PC에 꽂아도 이어서 쓸 수 있습니다.

    USB 준비

    NTFS 형식
    필수exFAT·FAT32 USB에서는 NTFS로 포맷하라는 안내만 띄우고 종료됩니다.
    용량 4GB 이상
    최소저장 공간 기준입니다. 압축을 푼 앱만 약 0.7GB이고, 쓰는 동안 기억과 데이터가 늘어납니다.
    USB 3.0 이상
    권장파일이 3만 개 가까이 되어서, 느린 USB에서는 압축 풀기와 첫 실행에 시간이 오래 걸립니다.

    포맷하면 USB 안의 파일이 모두 지워집니다. 필요한 파일은 먼저 다른 곳에 옮겨 두세요.

    1. USB 형식 확인

      파일 탐색기에서 USB를 오른쪽 클릭하고 [속성]을 열어 ‘파일 시스템’을 확인하세요.

      NTFS가 아니면 USB를 오른쪽 클릭 → [포맷] → 파일 시스템 ‘NTFS’ → [시작]으로 포맷하세요.

    2. 압축 풀기

      USB에 Scheherazade 같은 새 폴더를 만드세요.

      받은 Scheherazade-Portable-버전-win-x64.zip의 압축을 그 폴더에 모두 풀어 주세요.

      ZIP을 연 채로 그 안에서 바로 실행하지 마세요.

    3. 앱 실행

      그 폴더의 Scheherazade.exe를 실행하세요.

      ‘Windows의 PC 보호’ 창이 뜨면, 먼저 ZIP을 choam.studio나 GitHub의 CHOAM-CO/scheherazade-releases에서 받았는지, 파일 이름이 Scheherazade-Portable-버전-win-x64.zip 형식인지 확인하세요.

      맞다면 [추가 정보]를 누른 뒤 [실행]을 누르세요. 아직 코드 서명이 없어서 게시자가 ‘알 수 없음’으로 표시됩니다.

      다른 곳에서 받은 파일이라면 실행하지 말고 삭제하세요.

    4. data 폴더 그대로 두기

      처음 실행하면 같은 폴더에 data 폴더가 생깁니다. 기억과 설정, 키가 모두 여기에 저장됩니다.

      data 폴더는 Scheherazade.exe와 같은 폴더에 그대로 두세요.

    • USB를 뽑기 전에 Scheherazade를 종료하고, 작업 표시줄의 ‘하드웨어 안전하게 제거’로 꺼내세요.
    • API 키와 토큰은 다른 PC에서도 쓸 수 있도록 USB에 암호화되지 않은 파일로 저장됩니다. USB를 가진 사람은 키를 읽을 수 있으니, USB도 키처럼 보관하세요.
    • Claude 계정 로그인은 USB에 저장되지 않습니다. 다른 PC에서는 Claude에 한 번 다시 로그인하세요.
    • PC마다 드라이브 문자(E:, F:)가 달라져도 괜찮습니다.
    • 업데이트는 자동으로 되지 않습니다. 앱을 종료하고 새 ZIP의 내용을 같은 폴더에 덮어쓰세요. data 폴더는 지우지 마세요.

    Linux

    x86_64(64비트 Intel·AMD) Linux용 AppImage입니다.

    1. 실행 권한 주기

      받은 Scheherazade-버전-x86_64.AppImage에 실행 권한을 주세요.

      파일 관리자의 속성에서 실행을 허용하거나, 파일이 있는 폴더의 터미널에서 아래 명령을 실행하세요.

      chmod +x Scheherazade-*-x86_64.AppImage

    2. 앱 실행

      파일을 더블클릭하거나 터미널에서 실행하세요.

      ./Scheherazade-*-x86_64.AppImage

    업데이트는 자동으로 설치되지 않습니다. 새 버전 알림이 오면 새 AppImage를 받아 교체하고, 새 파일에도 위와 같이 실행 권한을 주세요.

    처음 켜면

    설정 화면이 열리면 대화에 쓸 두뇌를 연결하세요. 이미 쓰는 Claude·ChatGPT 구독이나 Anthropic API 키, Ollama 중 하나를 고르면 됩니다.

    Claude 구독으로 쓰려면 유료 Claude 플랜이 필요합니다. 로그인은 앱 안에서 합니다.

    Mac

    For Macs with Apple silicon (M series) only. There is no Intel Mac build yet.

    1. Open the dmg

      Double-click the Scheherazade-version-arm64.dmg you downloaded.

    2. Move it to Applications

      In the window that opens, drag Scheherazade onto the Applications folder.

    3. Open the app

      Open Scheherazade from Applications.

    If macOS says the app is “damaged and can’t be opened”

    The app is not yet signed with an Apple Developer ID or notarized, so macOS can block a copy downloaded from the internet.

    Only if you see this message, first check that the dmg came from choam.studio or CHOAM-CO/scheherazade-releases on GitHub.

    If the file came from anywhere else, do not run it; delete it.

    If it did, open Terminal, run the line below, then open the app again.

    xattr -dr com.apple.quarantine /Applications/Scheherazade.app

    It removes only the macOS quarantine attribute (com.apple.quarantine) from Scheherazade and the files inside it. It does not change other apps or your Mac’s security settings.

    If you put the app somewhere other than Applications, change the path to match. You may need it again after installing a freshly downloaded copy.

    Updates are not installed for you. When the app says a new version is out, download the new dmg and replace the app the same way. Settings, memory and profiles carry over.

    Windows

    An installer for 64-bit (x64) Windows.

    1. Run the installer

      Run the Scheherazade-Setup-version.exe you downloaded.

    2. Check the source, then run

      If “Windows protected your PC” appears, first check that the file came from choam.studio or CHOAM-CO/scheherazade-releases on GitHub and that its name matches the one above.

      If it does, choose More info, then Run anyway. The installer is not code-signed yet, so the publisher shows as unknown.

      If the file came from anywhere else, do not run it; delete it.

    3. Open the app

      When setup finishes, open Scheherazade from the Start menu.

    Updates download and install by themselves.

    Windows portable (USB)

    A Windows build you run from a USB drive without installing. Memory, settings, profiles and keys are stored in its folder on the drive, so you can plug it into another Windows PC and carry on.

    Prepare the USB drive

    NTFS format
    RequiredOn an exFAT or FAT32 drive the app only asks you to format it as NTFS, then closes.
    4 GB or more
    MinimumStorage space, not memory. The unzipped app alone takes about 0.7 GB, and memory and data grow as you use it.
    USB 3.0 or faster
    RecommendedThe app is close to 30,000 files, so unzipping and the first start take a long time on a slow drive.

    Formatting erases everything on the drive. Copy anything you need somewhere else first.

    1. Check the drive format

      In File Explorer, right-click the drive and open Properties to see its File system.

      If it is not NTFS, right-click the drive, choose Format, set File system to NTFS, then Start.

    2. Extract the ZIP

      Make a new folder on the drive, such as Scheherazade.

      Extract everything in Scheherazade-Portable-version-win-x64.zip into it.

      Do not run the app from inside the open ZIP.

    3. Run the app

      Run Scheherazade.exe in that folder.

      If “Windows protected your PC” appears, first check that the ZIP came from choam.studio or CHOAM-CO/scheherazade-releases on GitHub and that its name has the form Scheherazade-Portable-version-win-x64.zip.

      If it does, choose More info, then Run anyway. The app is not code-signed yet, so the publisher shows as unknown.

      If the file came from anywhere else, do not run it; delete it.

    4. Keep the data folder

      The first start creates a data folder next to it. Memory, settings and keys all live there.

      Keep it in the same folder as Scheherazade.exe.

    • Before unplugging, quit Scheherazade, then use Safely Remove Hardware in the taskbar.
    • API keys and tokens are stored on the drive as unencrypted files so they work on any PC. Anyone holding the drive can read them; keep it as safe as the keys themselves.
    • A Claude account login is not stored on the drive. Sign in to Claude once on each PC.
    • The drive letter (E:, F:) may change from PC to PC; that is fine.
    • The portable build does not update itself. Quit it and copy the new ZIP’s contents over the same folder, keeping the data folder.

    Linux

    An AppImage for x86_64 (64-bit Intel or AMD) Linux.

    1. Make it executable

      Make the downloaded Scheherazade-version-x86_64.AppImage executable.

      Either allow it in your file manager’s properties, or run this in a terminal in the folder that holds it.

      chmod +x Scheherazade-*-x86_64.AppImage

    2. Run it

      Double-click the file, or run it from the terminal.

      ./Scheherazade-*-x86_64.AppImage

    Updates are not installed for you. When the app says a new version is out, download the new AppImage, replace the old one, and make the new file executable as above.

    A setup screen opens where you connect the brain it talks with. Pick a Claude or ChatGPT subscription you already have, an Anthropic API key, or Ollama.

    Using a Claude subscription needs a paid Claude plan. You sign in inside the app.

    Mac

    Apple シリコン(M シリーズ)搭載の Mac 専用です。Intel Mac 向けのファイルはまだありません。

    1. dmg を開く

      ダウンロードした Scheherazade-バージョン-arm64.dmg をダブルクリックして開きます。

    2. 「アプリケーション」へ移す

      開いたウインドウで、Scheherazade のアイコンを「アプリケーション」フォルダへドラッグします。

    3. アプリを開く

      「アプリケーション」フォルダから Scheherazade を開きます。

    「壊れているため開けません」と表示されたら

    このアプリはまだ Apple の Developer ID による署名と公証を受けていないため、インターネットからダウンロードしたものを macOS がブロックすることがあります。

    このメッセージが出たときだけ、まず dmg を choam.studio か GitHub の CHOAM-CO/scheherazade-releases から入手したかを確認してください。

    ほかの場所から入手したファイルなら、実行せずに削除してください。

    上の公式の入手元から入手したと確認できた場合のみ、ターミナルを開いて下の 1 行を実行し、もう一度アプリを開きます。

    xattr -dr com.apple.quarantine /Applications/Scheherazade.app

    このコマンドは、Scheherazade とその中のファイルから macOS の隔離属性(com.apple.quarantine)だけを取り除きます。ほかのアプリや Mac 全体のセキュリティ設定は変わりません。

    アプリを「アプリケーション」以外の場所に置いた場合は、パスをその場所に合わせて変えてください。新しくダウンロードしたファイルで入れ直したときは、再度この操作が必要になることがあります。

    アップデートは自動ではインストールされません。新しいバージョンのお知らせが届いたら、新しい dmg をダウンロードして同じ手順でアプリを置き換えてください。設定、記憶、プロファイルはそのまま残ります。

    Windows

    64 ビット(x64)版 Windows 用のインストーラーです。

    1. インストーラーを実行

      ダウンロードした Scheherazade-Setup-バージョン.exe を実行します。

    2. 入手元を確かめて実行

      「Windows によって PC が保護されました」と表示されたら、まずファイルを choam.studio か GitHub の CHOAM-CO/scheherazade-releases から入手したか、ファイル名が上と同じかを確認してください。

      公式の入手元から入手し、ファイル名も同じだと確認できた場合のみ、[詳細情報]を押してから[実行]を押します。まだコード署名がないため、発行元は「不明」と表示されます。

      ほかの場所から入手したファイルなら、実行せずに削除してください。

    3. アプリを開く

      インストールが終わったら、スタートメニューから Scheherazade を開きます。

    アップデートはアプリが自動的にダウンロードしてインストールします。

    Windows ポータブル(USB)

    インストールせずに、USB メモリに入れて持ち歩いて使う Windows 版です。記憶、設定、プロファイル、キーは USB 内のフォルダに保存されるので、別の Windows PC に挿しても続きから使えます。

    USB メモリの準備

    NTFS 形式
    必須exFAT や FAT32 の USB では、NTFS でフォーマットするよう案内が出て、アプリは終了します。
    容量 4GB 以上
    最低ストレージ容量の目安です。展開したアプリだけで約 0.7GB あり、使ううちに記憶とデータが増えていきます。
    USB 3.0 以上
    推奨ファイル数が 3 万近くあるため、低速な USB メモリでは展開と初回起動に時間がかかります。

    フォーマットすると USB 内のファイルはすべて消えます。必要なファイルは先に別の場所へ移しておいてください。

    1. USB の形式を確認

      エクスプローラーで USB を右クリックして[プロパティ]を開くと「ファイル システム」が表示されます。

      NTFS でなければ、USB を右クリック →[フォーマット]→ ファイル システムを「NTFS」→[開始]でフォーマットします。

    2. ZIP を展開

      USB に Scheherazade などの新しいフォルダを作ります。

      ダウンロードした Scheherazade-Portable-バージョン-win-x64.zip の中身をすべてそのフォルダに展開します。

      ZIP を開いたまま、その中から直接実行しないでください。

    3. アプリを実行

      そのフォルダの Scheherazade.exe を実行します。

      「Windows によって PC が保護されました」と表示されたら、まず ZIP を choam.studio か GitHub の CHOAM-CO/scheherazade-releases から入手したか、ファイル名が Scheherazade-Portable-バージョン-win-x64.zip の形式かを確認してください。

      公式の入手元から入手し、ファイル名の形式も合っていると確認できた場合のみ、[詳細情報]を押してから[実行]を押します。まだコード署名がないため、発行元は「不明」と表示されます。

      ほかの場所から入手したファイルなら、実行せずに削除してください。

    4. data フォルダはそのままに

      初めて起動すると、同じフォルダに data フォルダができます。記憶、設定、キーはすべてここに保存されます。

      Scheherazade.exe と同じフォルダに置いたままにしてください。

    • USB を抜く前に Scheherazade を終了し、タスクバーの「ハードウェアを安全に取り外す」から取り出してください。
    • API キーとトークンは、ほかの PC でも使えるように、暗号化されていないファイルとして USB に保存されます。USB を手にした人はキーを読めるので、キーそのものと同じように大切に保管してください。
    • Claude アカウントのログイン情報は USB に保存されません。別の PC では Claude にもう一度ログインしてください。
    • PC ごとにドライブ文字(E:、F:)が変わっても問題ありません。
    • アップデートは自動では行われません。アプリを終了し、新しい ZIP の中身を同じフォルダに上書きしてください。data フォルダは消さないでください。

    Linux

    x86_64(64 ビットの Intel・AMD)Linux 用の AppImage です。

    1. 実行権限を付ける

      ダウンロードした Scheherazade-バージョン-x86_64.AppImage に実行権限を付けます。

      ファイルマネージャーのプロパティで実行を許可するか、ファイルのあるフォルダでターミナルを開き、下のコマンドで実行権限を付けます。

      chmod +x Scheherazade-*-x86_64.AppImage

    2. 起動する

      ファイルをダブルクリックするか、ターミナルから実行します。

      ./Scheherazade-*-x86_64.AppImage

    アップデートは自動ではインストールされません。新しいバージョンのお知らせが届いたら、新しい AppImage をダウンロードして置き換え、新しいファイルにも上と同じように実行権限を付けてください。

    初めて起動したら

    設定画面が開くので、会話に使う頭脳をつなぎます。すでに使っている Claude や ChatGPT のサブスクリプション、Anthropic の API キー、Ollama のどれかを選んでください。

    Claude のサブスクリプションで使うには、有料の Claude プランが必要です。ログインはアプリの中で行います。
