    설치 방법How to installインストール方法

    받은 운영체제별 파일 순서대로 설치하세요. 무료 배포(구독 없음) · 계정 및 이메일 불필요 · 외부 전송 없는 로컬 평문 기억 원칙으로 제공되며, 모든 플랫폼에서 앱 내 자동 업데이트를 지원합니다.

    Follow the steps for the build you downloaded. Scheherazade is free forever (no subscription), requires no account or email, keeps memory in plain local files with zero telemetry, and updates inside the app on every platform.

    ダウンロードしたファイルに合った手順で導入してください。無料配布（サブスクリプションなし）・アカウント／メール不要・外部送信のないローカル平文ファイル記憶で提供され、すべての OS でアプリ内自動アップデートに対応しています。

    Mac

    Apple 실리콘(M 시리즈) Mac 전용이며, CHOAM Co., Ltd. Apple Developer ID 서명 및 Apple 공증(notarized)을 완료한 공식 배포본입니다.

    1. dmg 열기

      받은 Scheherazade-버전-arm64.dmg를 더블클릭하여 여세요.

    2. 응용 프로그램 폴더로 옮기기

      열린 창에서 Scheherazade 아이콘을 응용 프로그램(Applications) 폴더로 끌어다 놓으세요.

    3. 앱 열기

      응용 프로그램 폴더에서 Scheherazade를 실행하세요. Apple 공증이 완료되어 별도의 터미널 명령 없이 바로 열립니다.

    새 버전이 출시되면 앱 내 업데이트 진행률 배너에서 다운로드 상태를 확인하고 지금 재시작을 눌러 자동 업데이트할 수 있습니다. 설정과 기억, 멀티 프로필은 그대로 유지됩니다.

    Windows

    64비트(x64) Windows용 설치 파일이며, CHOAM Co., Ltd. 상용 Authenticode 코드 서명이 적용되어 있습니다.

    1. 설치 파일 실행

      받은 Scheherazade-Setup-버전.exe를 실행하세요.

    2. 앱 열기

      설치가 끝나면 시작 메뉴나 바탕화면에서 Scheherazade를 여세요.

    • 신규 릴리스 직후 평판 누적 기간에 간헐적으로 Windows SmartScreen 안내 창이 뜨는 경우, 공식 배포처(choam.studio 또는 GitHub CHOAM-CO/scheherazade-releases)에서 받은 파일인지와 게시자(CHOAM Co., Ltd.)를 확인한 뒤 실행하세요.

    새 버전이 출시되면 앱 내 업데이트 진행률 배너에서 다운로드 상태를 확인하고 지금 재시작을 눌러 자동 업데이트할 수 있습니다.

    Windows 포터블 (USB)

    설치 없이 NTFS USB에 넣어 다니며 쓰는 Windows 포터블 버전(CHOAM Co., Ltd. 코드 서명 완료)입니다. PIN 잠금으로 타인 PC에서도 안전하게 보호할 수 있으며, 데스크톱 세헤라자드의 기억을 이어받아 다른 Windows PC에 꽂아도 그대로 이어서 쓸 수 있습니다.

    USB 준비

    NTFS 형식
    필수exFAT·FAT32 USB에서는 NTFS 포맷 안내만 표시하고 종료됩니다.
    용량 4GB 이상
    최소압축을 푼 앱 본체가 약 0.7GB이며, 사용할수록 기억과 작업 데이터가 늘어납니다.
    USB 3.0 이상
    권장내부 파일 수가 많아 고속 USB에서 압축 해제와 첫 실행이 빠릅니다.

    포맷하면 USB 안의 기존 파일이 모두 지워지므로, 필요한 파일은 먼저 백업하세요.

    1. USB 형식 확인

      파일 탐색기에서 USB를 오른쪽 클릭하고 [속성]에서 파일 시스템이 NTFS인지 확인하세요. NTFS가 아니면 [포맷]에서 NTFS로 포맷하세요.

    2. 압축 풀기

      USB 안에 Scheherazade 등 새 폴더를 만들고 Scheherazade-Portable-버전-win-x64.zip의 압축을 모두 푸세요. ZIP을 연 채로 바로 실행하지 마세요.

    3. 앱 실행 및 PIN·기억 설정

      압축을 푼 폴더의 Scheherazade.exe를 실행하세요. 필요하면 PIN 잠금을 켜거나 데스크톱 세헤라자드의 기억을 이어받을 수 있습니다.

    4. data 폴더 보존

      첫 실행 시 같은 위치에 생성되는 data 폴더에 기억과 설정, 프로필이 모두 저장됩니다. Scheherazade.exe와 같은 폴더에 그대로 두세요.

    • USB를 분리하기 전에 Scheherazade를 종료하고 작업 표시줄의 ‘하드웨어 안전하게 제거’를 사용하세요.
    • 공유 PC 사용 시 앱 설정에서 PIN 잠금을 활성화하고, 물리적 USB 분실에 유의하세요.
    • 신규 릴리스 초기 평판 누적 중 SmartScreen 창이 간헐적으로 뜨면 공식 배포처와 서명자(CHOAM Co., Ltd.)를 확인한 뒤 실행하세요.
    • 포터블 버전도 앱 내 업데이트 진행률 배너에서 새 버전을 받아 지금 재시작으로 자동 업데이트됩니다. data 폴더의 기억은 그대로 보존됩니다.

    Linux

    x86_64(64비트 Intel·AMD) Linux용 AppImage입니다.

    1. 실행 권한 부여

      받은 Scheherazade-버전-x86_64.AppImage에 실행 권한을 부여하세요. 파일 관리자 속성에서 허용하거나 터미널에서 아래 명령을 실행합니다.

      chmod +x Scheherazade-*-x86_64.AppImage

    2. 앱 실행

      파일을 더블클릭하거나 터미널에서 실행하세요.

      ./Scheherazade-*-x86_64.AppImage

    Linux(AppImage) 버전도 새 버전이 나오면 앱 내 업데이트 진행률 배너에서 다운로드 상태를 확인하고 지금 재시작을 눌러 자동 업데이트할 수 있습니다.

    Windows portable (USB)

    A code-signed (CHOAM Co., Ltd.) Windows build that runs straight from an NTFS USB drive without installing. Protect your workspace on shared PCs with a PIN lock, hand over memory from your desktop Scheherazade, and plug into another Windows PC to continue right where you left off.

    Prepare the USB drive

    NTFS format
    RequiredOn exFAT or FAT32 drives, the app prompts you to format as NTFS and exits.
    4 GB or more
    MinimumThe extracted app uses about 0.7 GB, and local memory grows as you work.
    USB 3.0 or faster
    RecommendedFast flash storage speeds up extraction and first launch.

    Formatting erases everything on the drive. Back up any existing files first.

    1. Verify NTFS format

      Right-click the USB drive in File Explorer, open Properties, and confirm File system is NTFS (or Format as NTFS).

    2. Extract the ZIP

      Create a folder such as Scheherazade on the drive and extract all contents of Scheherazade-Portable-version-win-x64.zip into it. Do not launch from inside the unextracted ZIP.

    3. Launch & configure PIN or memory handoff

      Run Scheherazade.exe from that folder. Enable PIN lock for shared machines or import memory from your desktop installation if desired.

    4. Keep the data folder

      First launch creates a data folder beside Scheherazade.exe holding your memory, profiles, and settings. Keep them together.

    • Quit Scheherazade and use Safely Remove Hardware in the taskbar before unplugging the USB drive.
    • Turn on PIN lock when carrying the drive across shared PCs, and guard physical access to the drive.
    • If SmartScreen appears briefly on a brand-new release while reputation builds, confirm the official source and CHOAM Co., Ltd. signature before running.
    • The portable build updates in-app as well: check the update progress banner and click Restart now. Your data folder stays untouched.

    Linux

    An AppImage for x86_64 (64-bit Intel or AMD) Linux.

    1. Make it executable

      Grant execute permission to Scheherazade-version-x86_64.AppImage via your file manager’s properties or in a terminal:

      chmod +x Scheherazade-*-x86_64.AppImage

    2. Run it

      Double-click the file or run it from a terminal:

      ./Scheherazade-*-x86_64.AppImage

    The Linux AppImage also updates automatically inside the app: watch the update progress banner and click Restart now.

    Windows ポータブル（USB）

    インストール不要で NTFS 形式の USB メモリから直接起動できる Windows ポータブル版（CHOAM Co., Ltd. コード署名済み）です。PIN ロックで共有 PC でも保護でき、デスクトップ版 Scheherazade の記憶を引き継いで別の Windows PC でも続きから使えます。

    USB メモリの準備

    NTFS 形式
    必須exFAT や FAT32 の USB では NTFS フォーマット案内を表示して終了します。
    容量 4GB 以上
    最低展開したアプリ本体が約 0.7GB で、利用に応じて記憶データが増えます。
    USB 3.0 以上
    推奨ファイル数が多いため、高速な USB メモリほど展開と初回起動が快適です。

    フォーマットすると USB 内のファイルはすべて消去されます。必要なデータは先に退避してください。

    1. USB の形式を確認

      エクスプローラーで USB を右クリックして [プロパティ] を開き、ファイルシステムが NTFS であることを確認します（異なる場合は NTFS でフォーマットします）。

    2. ZIP を展開

      USB に Scheherazade などのフォルダを作り、Scheherazade-Portable-バージョン-win-x64.zip の中身をすべて展開します。未展開の ZIP 内から直接起動しないでください。

    3. 起動と PIN・記憶引き継ぎ設定

      展開先フォルダの Scheherazade.exe を実行します。必要に応じて PIN ロックやデスクトップ版の記憶引き継ぎを設定できます。

    4. data フォルダの保持

      初回起動時に作成される data フォルダに記憶・設定・プロファイルが保存されます。Scheherazade.exe と同じフォルダに置いたままにしてください。

    • USB を抜く前に Scheherazade を終了し、タスクバーの「ハードウェアを安全に取り外す」を使用してください。
    • 共有 PC で使う際は PIN ロックを有効にし、USB メモリ自体の紛失にご注意ください。
    • 新リリース直後に SmartScreen が表示された場合は、公式配布元と署名者（CHOAM Co., Ltd.）を確認のうえ実行してください。
    • ポータブル版もアプリ内のアップデート進捗バナーから今すぐ再起動で自動アップデートされます。data フォルダの記憶はそのまま残ります。
