    오류 코드Error codesエラーコード

    빨간 막대는 대괄호 안의 코드로 시작해요. 같은 코드를 아래에서 찾아 주세요.The red bar starts with a code in brackets. Find it below.赤いバーは角かっこ内のコードで始まります。同じコードを下から探してください。

    에이전트가 시작되지 않았거나 멈췄어요Agent didn't start / stoppedエージェントが起動しない・止まった

    [CLI_LOGIN_EXPIRED]

    이 컴퓨터의 Claude Code 로그인이 만료됐어요.The Claude Code login on this computer has expired.このパソコンの Claude Code のログインが切れています。

    터미널에서 claude를 한 번 실행하거나 설정 > 모델에서 다시 로그인해 주세요.Run claude once in a terminal to refresh it, or log in again from Settings > Model.ターミナルで claude を一度実行するか、設定 > モデル からもう一度ログインしてください。

    [CLI_LOGIN_MISSING]

    이 컴퓨터에 Claude Code 로그인이 없어요.There is no Claude Code login on this computer.このパソコンに Claude Code のログインがありません。

    설정 > 모델에서 로그인하거나 터미널에서 claude를 한 번 실행해 주세요.Log in from Settings > Model, or run claude once in a terminal.設定 > モデル からログインするか、ターミナルで claude を一度実行してください。

    [CLI_CREDENTIALS_UNREADABLE]

    Claude Code 로그인은 있지만 읽지 못했어요.The Claude Code login exists but could not be read.Claude Code のログインはありますが、読み取れませんでした。

    다시 시도해 주세요. 계속 그러면 설정 > 모델에서 다시 로그인해 주세요.Try again. If it keeps failing, log in again from Settings > Model.もう一度お試しください。続く場合は 設定 > モデル からもう一度ログインしてください。

    [CREDENTIALS_MISSING]

    고른 모델 연결의 키나 토큰이 저장돼 있지 않아요.The key or token for the chosen model connection is not on file.選んだモデル接続のキーまたはトークンが保存されていません。

    설정 > 모델에서 입력해 주세요.Enter it in Settings > Model.設定 > モデル で入力してください。

    [MODEL_MISSING]

    고른 모델 연결에 모델이 선택돼 있지 않아요.The chosen model connection has no model selected.選んだモデル接続にモデルが設定されていません。

    설정 > 모델에서 골라 주세요.Pick one in Settings > Model.設定 > モデル で選んでください。

    [CONFIG_INCOMPLETE]

    사용자 지정 연결의 주소(Base URL)가 비어 있어요.The proxy address for the custom connection is empty.カスタム接続のアドレス（Base URL）が空です。

    설정 > 모델에서 Base URL을 입력해 주세요.Enter the Base URL in Settings > Model.設定 > モデル で Base URL を入力してください。

    [LANE_UNAVAILABLE]

    연결한 서비스를 저장된 키, 모델, 주소로 쓸 수 없어요.A service you connected cannot be used with its saved key, model or address.接続したサービスを、保存されたキー・モデル・アドレスでは使えません。

    설정 > 모델 및 제공자에서 키와 모델을 다시 확인해 주세요.Recheck its key and model in Settings > Model & Providers.設定 > モデルとプロバイダー でキーとモデルを確認してください。

    [TIMEOUT_BOOT_STAGE]

    엔진이 뜨기 전에 시작이 멈췄어요.Startup stalled before the engine came up.エンジンが起動する前に開始が止まりました。

    로그를 확인해 주세요. 앱을 다시 시작하고, 계속 그러면 엔진 설정을 확인해 주세요.Open Logs. Restart the app; if it repeats, check the engine settings.ログを確認してください。アプリを再起動し、続く場合はエンジン設定を確認してください。

    [TIMEOUT_ENGINE_SPAWN]

    에이전트 프로세스가 뜬 뒤 엔진이 제때 올라오지 못했어요.The engine did not come up in time after the agent process started.エージェントのプロセスが起動したあと、エンジンが時間内に立ち上がりませんでした。

    로그를 확인해 주세요. 앱을 다시 시작하고, 계속 그러면 다른 모델이나 제공자를 골라 주세요.Open Logs. Restart the app; if it repeats, pick another model or provider.ログを確認してください。アプリを再起動し、続く場合は別のモデルかプロバイダーを選んでください。

    [TIMEOUT_NO_HEARTBEAT]

    시작은 끝났지만 에이전트가 연결됐다고 알려 오지 않았어요.Startup finished but the agent never reported that it was connected.起動は終わりましたが、エージェントから接続の通知がありませんでした。

    로그를 확인해 주세요. 앱을 다시 시작하고, 계속 그러면 채널 연결을 확인해 주세요.Open Logs. Restart the app; if it repeats, check the channel connection.ログを確認してください。アプリを再起動し、続く場合はチャンネル接続を確認してください。

    [TIMEOUT]

    시작이 너무 오래 걸렸고, 어느 단계에서 멈췄는지 앱이 알지 못해요.Startup took too long and the app has no information about the stage it stopped at.起動に時間がかかりすぎ、どこで止まったかをアプリが特定できませんでした。

    로그를 확인해 주세요.Open Logs.ログを確認してください。

    [KEY_ERROR]

    저장된 제공자 키를 운영체제 자격 증명 저장소에서 읽지 못했어요.The stored provider key could not be read from the OS credential store.保存されたプロバイダーのキーを OS の資格情報ストアから読み取れませんでした。

    설정 > 모델에서 키를 다시 저장해 주세요.Re-save the key in Settings > Model.設定 > モデル でキーを保存し直してください。

    [LOGIN_REQUIRED]

    모델 연결에 아직 하지 않은 로그인이 필요해요.The model connection needs a sign-in that has not happened yet.モデル接続に、まだ済んでいないログインが必要です。

    설정 > 모델에서 로그인해 주세요. 로그인하면 에이전트가 스스로 시작해요.Log in from Settings > Model. The agent starts by itself once you are signed in.設定 > モデル でログインしてください。ログインするとエージェントは自動で起動します。

    [PROVIDER_NOT_WIRED]

    저장된 제공자 이름을 앱이 알지 못하거나, 그 설정이 올바르지 않아요.The saved provider name is not one the app knows, or its setup is invalid.保存されたプロバイダー名をアプリが認識できないか、設定が正しくありません。

    설정 > 모델에서 제공자를 다시 골라 주세요.Pick a provider again in Settings > Model.設定 > モデル でプロバイダーを選び直してください。

    [MODEL_SELECTION_FAILED]

    고른 모델이나 추론 강도가 거절됐어요.The chosen model or effort level was rejected.選んだモデルまたは推論の強さが受け付けられませんでした。

    설정 > 모델에서 다른 모델이나 추론 강도를 골라 주세요.Pick a different model or effort in Settings > Model.設定 > モデル で別のモデルか推論の強さを選んでください。

    [CLI_MISSING]

    Antigravity 명령줄 도구를 설치하지 못했어요.The Antigravity command-line tool could not be installed.Antigravity のコマンドラインツールをインストールできませんでした。

    인터넷 연결을 확인하고 앱을 다시 열어 주세요.Check your internet connection, then reopen the app.インターネット接続を確認して、アプリを開き直してください。

    [PROXY_UNAVAILABLE]

    고른 연결에 필요한 로컬 프록시가 뜨지 않았어요.The local proxy the chosen connection needs did not come up.選んだ接続に必要なローカルプロキシが起動しませんでした。

    앱을 다시 시작해 주세요. 계속 그러면 다른 제공자를 골라 주세요.Restart the app. If it repeats, pick another provider.アプリを再起動してください。続く場合は別のプロバイダーを選んでください。

    [OLLAMA_UNAVAILABLE]

    로컬 Ollama 서비스가 실행 중이 아니에요.The local Ollama service is not running.ローカルの Ollama サービスが動いていません。

    Ollama를 실행한 뒤 다시 시작해 주세요.Start Ollama, then restart the agent.Ollama を起動してから、もう一度開始してください。

    [APP_FILES_MISSING]

    앱에 함께 들어 있어야 할 파일 하나가 설치본에서 빠져 있어요.A file the app ships is missing from its own install.アプリに同梱されるファイルが1つ、インストール先にありません。

    앱을 다시 설치해 주세요.Reinstall the app.アプリをインストールし直してください。

    [HARNESS_STALE]

    이 버전에 맞춰 에이전트 지침 파일을 갱신하지 못했어요.The agent's instruction files could not be updated for this version.このバージョンに合わせてエージェントの指示ファイルを更新できませんでした。

    앱을 다시 열어 주세요. 다시 열면 갱신을 다시 시도해요.Reopen the app. Reopening retries the update.アプリを開き直してください。開き直すと更新をやり直します。

    [APP_WRITTEN_DAMAGED]

    직접 수정한 파일의 기록이 손상됐어요.The record of the files you edited is damaged.編集したファイルの記録が壊れています。

    재설정해 주세요. 수정한 내용은 그대로 남아요.Reset it. Your edits stay.リセットしてください。編集した内容はそのまま残ります。

    [HARNESS_ERROR]

    에이전트의 위임 지침을 갱신하지 못했어요.The agent's delegation instructions could not be updated.エージェントの委任の指示を更新できませんでした。

    앱을 다시 열어 주세요. 계속 그러면 로그를 확인해 주세요.Reopen the app. If it repeats, open Logs.アプリを開き直してください。続く場合はログを確認してください。

    [SPAWN_FAILED]

    에이전트 프로세스를 아예 시작하지 못했어요.The agent process could not be started at all.エージェントのプロセスをまったく起動できませんでした。

    앱을 다시 시작해 주세요. 계속 그러면 로그를 확인해 주세요.Restart the app. If it repeats, open Logs.アプリを再起動してください。続く場合はログを確認してください。

    [CRASH_LOOP]

    에이전트 프로세스가 시작하자마자 계속 꺼져요.The agent process keeps exiting shortly after it starts.エージェントのプロセスが起動直後に繰り返し終了します。

    앱을 종료했다가 다시 열어 주세요. 계속 그러면 설정 값을 확인해 주세요.Quit and reopen the app. If it repeats, check the values you entered at setup.アプリを終了して開き直してください。続く場合は設定時の入力値を確認してください。

    [ENGINE_START_FAILED]

    연속 종료가 이어졌고, 엔진이 스스로 시작 오류를 기록했어요.The same quick-exit streak, and the engine recorded its own startup error.同じ連続終了が続き、エンジン自身が起動エラーを記録しました。

    설정 > 모델에서 다른 모델을 고르거나 제공자를 끈 뒤 다시 시작해 주세요.Pick another model or turn a provider off in Settings > Model, then start again.設定 > モデル で別のモデルを選ぶかプロバイダーをオフにしてから、もう一度開始してください。

    [AGENT_EXITED]

    에이전트 프로세스가 시작된 뒤 스스로 종료됐어요.The agent process started and then exited on its own.エージェントのプロセスが起動したあと、自力で終了しました。

    다시 시작해 주세요. 계속 그러면 로그를 확인해 주세요.Start it again. If it repeats, open Logs.もう一度開始してください。続く場合はログを確認してください。

    [STOP_UNCONFIRMED]

    중지나 재시작이 예전 프로세스가 정말 끝났는지 확인하지 못했어요.A stop or restart could not confirm the old process really ended.停止または再起動で、以前のプロセスが本当に終わったか確認できませんでした。

    잠시 기다린 뒤 다시 시도해 주세요.Wait a moment, then try again.少し待ってから、もう一度お試しください。

    [DISCORD_TOKEN_BAD]

    Discord 봇 토큰이 없거나 거절됐어요.The Discord bot token is missing or was rejected.Discord のボットトークンがないか、受け付けられませんでした。

    채널에서 Discord를 다시 연결해 주세요.Reconnect Discord in Channels.チャンネルで Discord を接続し直してください。

    [SLACK_TOKEN_BAD]

    Slack 토큰이 없거나 거절됐어요.A Slack token is missing or was rejected.Slack のトークンがないか、受け付けられませんでした。

    채널에서 Slack 토큰 두 개를 다시 확인해 주세요.Recheck both Slack tokens in Channels.チャンネルで Slack の2つのトークンを確認してください。

    [TELEGRAM_TOKEN_BAD]

    Telegram 봇 토큰이 없거나 거절됐어요.The Telegram bot token is missing or was rejected.Telegram のボットトークンがないか、受け付けられませんでした。

    채널에서 텔레그램 토큰을 다시 확인해 주세요.Recheck the Telegram token in Channels.チャンネルで Telegram のトークンを確認してください。

    [CHANNEL_TOKEN_ERROR]

    메신저 토큰을 자격 증명 저장소에서 읽지 못했어요.A messenger token could not be read from the credential store.メッセンジャーのトークンを資格情報ストアから読み取れませんでした。

    채널에서 그 메신저를 다시 연결해 주세요.Reconnect that messenger in Channels.チャンネルでそのメッセンジャーを接続し直してください。

    [UNKNOWN]

    무언가 실패했지만 앱이 원인을 특정하지 못했어요.Something failed and the app cannot name the cause.何かが失敗しましたが、アプリが原因を特定できません。

    잠시 기다린 뒤 상태를 다시 확인해 주세요.Wait a moment, then check the status again.少し待ってから、状態をもう一度確認してください。

    마지막 답변이 실패했어요Last reply failed最後の返信が失敗した

    [RATE_LIMIT]

    모델 서비스가 사용량이나 속도 한도에 걸렸다고 알려요.The model service says a usage or rate limit was reached.モデルサービスが利用量またはレートの上限に達したと通知しています。

    잠시 기다렸다가 다시 보내 주세요. 필요하면 다른 모델을 골라 주세요.Wait a little and send again; pick another model if needed.少し待ってからもう一度送ってください。必要なら別のモデルを選んでください。

    [AUTH]

    모델 연결의 로그인이 만료됐거나 거절됐어요.The model connection's login is expired or rejected.モデル接続のログインが切れているか、拒否されました。

    다시 로그인해 주세요.Log in again.もう一度ログインしてください。

    [SERVER]

    모델 서비스가 과부하 상태이거나 서버 오류를 돌려주고 있어요.The model service is overloaded or returning server errors.モデルサービスが混雑しているか、サーバーエラーを返しています。

    잠시 후 다시 보내 주세요.Try again in a little while.少し時間をおいてから送り直してください。

    [TIMEOUT]

    모델이 제때 답하지 않았어요.The model did not answer in time.モデルが時間内に応答しませんでした。

    다시 보내 주세요. 계속 그러면 다른 모델을 골라 주세요.Send again; pick another model if it repeats.もう一度送ってください。続く場合は別のモデルを選んでください。

    [AGY_TURN_ERROR]

    Antigravity 모델 호출이 실패했어요.The Antigravity model call failed.Antigravity のモデル呼び出しが失敗しました。

    다시 보내 주세요. 계속 그러면 설정 > 모델에서 다른 모델을 골라 주세요.Send again; if it repeats, pick another model in Settings > Model.もう一度送ってください。続く場合は 設定 > モデル で別のモデルを選んでください。

    [PI_AI_ERROR]

    제공자가 호출을 거절했거나 호출이 실패했어요.The provider refused or failed the call.プロバイダーが呼び出しを拒否したか、呼び出しが失敗しました。

    요청을 바꿔 다시 보내 주세요. 계속 그러면 제공자 상태를 확인해 주세요.Send a different request; if it repeats, check the provider's status.リクエストを変えて送り直してください。続く場合はプロバイダーの状態を確認してください。

    [INVALID_REQUEST]

    제공자가 요청을 거절했어요. 텍스트 전용 모델에 이미지를 보낸 경우가 그래요.The provider rejected the request (for example, an image on a text-only model).プロバイダーがリクエストを拒否しました。テキスト専用モデルに画像を送った場合などです。

    입력을 바꿔 다시 보내 주세요.Change the input and send again.入力を変えて送り直してください。

    [TURN_FAILED]

    마지막 답변이 실패했고, 앱이 이유를 분류하지 못했어요.The last reply failed and the app cannot classify why.最後の返信が失敗し、アプリが理由を分類できませんでした。

    다시 보내 주세요. 계속 그러면 로그를 확인해 주세요.Send again; if it repeats, open Logs.もう一度送ってください。続く場合はログを確認してください。

    고쳐지지 않으면 빨간 막대를 캡처해서 mino@choam.studio로 보내 주세요.If the fix doesn't work, send a screenshot of the red bar to mino@choam.studio.解決しない場合は、赤いバーのスクリーンショットを mino@choam.studio までお送りください。
