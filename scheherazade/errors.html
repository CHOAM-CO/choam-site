    오류 코드Error codesエラーコード

    세헤라자드 빨간 막대의 오류는 대괄호 안의 코드로 시작합니다. 아래에서 같은 코드의 의미와 조치를 확인하십시오.Every error in Scheherazade's red bar begins with a code in square brackets. Find the same code below to see what happened and what to do next.Scheherazade の赤いバーに表示されるエラーは、必ず角かっこで囲まれたコードから始まります。下の一覧で同じコードを探すと、何が起きたのかと、どうすればよいかを確認できます。

    에이전트 시작 실패와 중단When the agent doesn't start or stopsエージェントが起動しない・止まったとき

    [CLI_LOGIN_EXPIRED]

    Claude Code 로그인이 만료됐습니다.Claude Code login expired.Claude Code のログインの有効期限が切れました。

    터미널에서 claude를 한 번 실행하거나 모델 및 프로바이더 탭에서 다시 로그인하십시오.Run claude once in a terminal to refresh it, or log in again from the Model & Providers tab.ターミナルで claude を一度実行するか、「モデルとプロバイダー」タブでもう一度ログインしてください。

    [CLI_LOGIN_MISSING]

    컴퓨터에 Claude Code 로그인이 없습니다.No Claude Code login was found on this machine.このコンピューターに Claude Code のログインがありません。

    모델 및 프로바이더 탭에서 로그인하거나 터미널에서 claude를 한 번 실행하십시오.Log in from the Model & Providers tab, or run claude once in a terminal.「モデルとプロバイダー」タブでログインするか、ターミナルで claude を一度実行してください。

    [CLI_CREDENTIALS_UNREADABLE]

    Claude Code 로그인 정보를 읽지 못했습니다.The Claude Code login could not be read.Claude Code のログインを読み取れませんでした。

    다시 시도하십시오. 계속 실패하면 모델 및 프로바이더 탭에서 다시 로그인하십시오.Try again. If it keeps failing, log in again from the Model & Providers tab.もう一度試してください。それでも続く場合は、「モデルとプロバイダー」タブでもう一度ログインしてください。

    [CREDENTIALS_MISSING]

    선택한 모델 연결 키가 없습니다.The key for the selected model connection is missing.選択したモデル接続のキーがありません。

    모델 및 프로바이더 탭에서 입력하십시오.Enter it in the Model & Providers tab.「モデルとプロバイダー」タブで入力してください。

    [MODEL_MISSING]

    이 연결에 선택된 모델이 없습니다.No model is selected for this connection.この接続にモデルが選ばれていません。

    모델 및 프로바이더 탭에서 선택하십시오.Pick one in the Model & Providers tab.「モデルとプロバイダー」タブで選んでください。

    [CONFIG_INCOMPLETE]

    프록시 주소가 없습니다.The proxy address is missing.プロキシのアドレスがありません。

    모델 및 프로바이더 탭에 Base URL을 입력하십시오.Enter the Base URL in the Model & Providers tab.「モデルとプロバイダー」タブで Base URL を入力してください。

    [LANE_UNAVAILABLE]

    연결 서비스를 쓸 수 없습니다.A connected service could not be used.接続したサービスを使えませんでした。

    모델 및 프로바이더 탭에서 키와 모델을 확인하십시오.Recheck its key and model in the Model & Providers tab.「モデルとプロバイダー」タブでキーとモデルを確認してください。

    [TIMEOUT_BOOT_STAGE]

    엔진 시작 전에 부팅이 멈췄습니다.The boot stalled before the engine started.エンジンが起動する前にブートが止まりました。

    로그를 확인하십시오. 앱을 다시 시작하고 반복되면 엔진 설정을 확인하십시오.Open Logs. Restart the app; if it repeats, check the engine settings.ログを確認してください。アプリを再起動し、それでも続く場合はエンジン設定を確認してください。

    [TIMEOUT_ENGINE_SPAWN]

    엔진이 제때 뜨지 않았습니다.The engine did not start in time.エンジンが時間内に起動しませんでした。

    로그를 확인하십시오. 앱을 다시 시작하고 반복되면 다른 모델을 선택하십시오.Open Logs. Restart the app; if it repeats, pick another model or provider.ログを確認してください。アプリを再起動し、それでも続く場合は別のモデルかプロバイダーを選んでください。

    [TIMEOUT_NO_HEARTBEAT]

    에이전트는 떴지만 연결되지 않았습니다.The agent booted but never connected.エージェントは起動しましたが接続されませんでした。

    로그를 확인하십시오. 앱을 다시 시작하고 반복되면 채널 연결을 확인하십시오.Open Logs. Restart the app; if it repeats, check the channel connection.ログを確認してください。アプリを再起動し、それでも続く場合はチャンネル接続を確認してください。

    [TIMEOUT]

    에이전트 시작 여부를 확인하지 못했습니다.Can't confirm whether the agent started.エージェントが起動したかどうかを確認できません。

    잠시 후 "상태 다시 확인"을 누르십시오.Wait a moment, then click Check status again.しばらく待ってから「状態を再確認」を押してください。

    [KEY_ERROR]

    저장된 키를 읽지 못했습니다.Couldn't read the stored key.保存されているキーを読み取れませんでした。

    앱을 종료했다가 다시 여십시오. 반복되면 설정할 때 입력한 값을 확인하십시오.Quit the app and reopen it. If it keeps happening, double-check the values you entered at setup.アプリを終了してもう一度開いてください。それでも続く場合は、セットアップで入力した値をもう一度確認してください。

    [LOGIN_REQUIRED]

    이 모델은 로그인해야 합니다.This model connection needs you to log in.このモデル接続はログインが必要です。

    모델 및 프로바이더 탭에서 로그인하십시오. 로그인하면 에이전트가 자동으로 시작됩니다.Log in from the Model & Providers tab. The agent starts by itself once you are signed in.「モデルとプロバイダー」タブでログインしてください。ログインするとエージェントが自動で起動します。

    [PROVIDER_NOT_WIRED]

    선택한 모델 연결이 준비되지 않았습니다.The model connection you chose isn't ready yet.選んだモデル接続の準備がまだできていません。

    모델 및 프로바이더 탭에서 Claude로 바꾸십시오.Switch the model to Claude in the Model & Providers tab, then quit and reopen the app.「モデルとプロバイダー」タブでモデルをClaudeに切り替えてから、アプリを終了してもう一度開いてください。

    [MODEL_SELECTION_FAILED]

    고른 모델이나 effort가 거부됐습니다.The selected model or effort was rejected.選んだモデルまたは推論の強さが拒否されました。

    모델 및 프로바이더 탭에서 다른 모델·effort를 고르십시오.Pick a different model or effort in the model picker of the Model & Providers tab.「モデルとプロバイダー」タブのモデルピッカーで、別のモデルまたは推論の強さを選んでください。

    [CLI_MISSING]

    Antigravity CLI 설치에 실패했습니다.The Antigravity CLI could not be installed.Antigravity CLIをインストールできませんでした。

    인터넷 연결을 확인하고 앱을 재시작하십시오.Check your internet connection, then quit the app and reopen it.インターネット接続を確認して、アプリを終了してもう一度開いてください。

    [PROXY_UNAVAILABLE]

    이 모델 연결의 로컬 프록시가 실행되지 않았습니다.The local proxy this model connection needs did not come up, and the agent was not started rather than routed somewhere unverified.このモデル接続に必要なローカルプロキシが起動しませんでした。

    앱을 다시 시작하십시오. 반복되면 모델 및 프로바이더 탭에서 연결을 바꾸십시오.Quit the app and reopen it. If it keeps happening, switch the model connection in the Model & Providers tab.アプリを終了してもう一度開いてください。それでも続く場合は、「モデルとプロバイダー」タブでモデル接続を切り替えてください。

    [OLLAMA_UNAVAILABLE]

    로컬 Ollama 데몬이 실행 중이 아닙니다.The local Ollama daemon is not running, so there is nothing for the agent to talk to.ローカルのOllamaデーモンが起動していません。

    Ollama를 실행하고 ollama list로 모델을 확인한 뒤 앱을 다시 여십시오.Start Ollama, confirm the model you picked is pulled (ollama list), then quit this app and reopen it.Ollamaを起動し、選んだモデルが取得済みか（ollama list）を確認してから、このアプリを終了してもう一度開いてください。

    [APP_FILES_MISSING]

    에이전트 설치 파일 일부가 없습니다.Part of the agent's own installation is missing.エージェントのインストールファイルの一部が見つかりません。

    앱을 재설치하십시오.Reinstall the app. Nothing you entered is lost -- your settings and memory live outside the app.アプリを再インストールしてください。設定と記憶は保持されます。

    [HARNESS_STALE]

    에이전트 지침 파일을 이 버전에 맞게 갱신하지 못했습니다.The agent's instruction files couldn't be updated for this version.このバージョン用にエージェントの指示ファイルを更新できませんでした。

    앱을 재시작하십시오. 다시 열면 업데이트를 재시도합니다.Quit the app and reopen it. Reopening retries the update, and the agent starts again once it succeeds.アプリを終了してもう一度開いてください。

    [APP_WRITTEN_DAMAGED]

    수정 파일 기록이 손상됐습니다.The record of your edited files is damaged.編集したファイルの記録が壊れています。

    재설정하십시오. 수정한 내용은 그대로 남습니다.Reset it. Your edits stay.リセットしてください。編集した内容はそのまま残ります。

    [HARNESS_ERROR]

    에이전트 위임 지침 갱신에 실패했습니다.The agent's delegation instructions couldn't be updated.エージェントの委任用の指示ファイルを更新できませんでした。

    앱을 다시 여십시오. 계속 실패하면 로그를 확인하십시오.Quit the app and reopen it to retry. If it still fails, open Logs.アプリを終了して開き直すと再試行します。失敗が続く場合はログを確認してください。

    [SPAWN_FAILED]

    에이전트를 시작하지 못했습니다.The agent could not be started at all.エージェントをまったく起動できませんでした。

    앱을 다시 시작하십시오. 반복되면 앱을 재설치하십시오.Quit the app and reopen it. If it keeps happening, reinstall the app.アプリを終了してもう一度開いてください。それでも続く場合は、アプリを再インストールしてください。

    [CRASH_LOOP]

    에이전트 프로세스가 반복 종료됩니다.The agent's process keeps exiting repeatedly. The exact cause isn't confirmed.エージェントのプロセスが繰り返し終了しています。

    앱을 종료했다가 다시 여십시오. 반복되면 설정할 때 입력한 값을 다시 확인하십시오.Quit the app and reopen it. If it keeps happening, double-check the values you entered at setup.アプリを終了してもう一度開いてください。それでも続く場合は、セットアップで入力した値をもう一度確認してください。

    [ENGINE_START_FAILED]

    엔진 시작에 실패했습니다.The engine failed to start.エンジンを起動できませんでした。

    모델 및 프로바이더 탭에서 다른 모델을 고르거나 프로바이더를 끄고 재시작하십시오.In the Model & Providers tab, pick another model or turn a provider off, then start the agent again.「モデルとプロバイダー」タブで別のモデルを選ぶか、プロバイダーを1つオフにしてから、エージェントをもう一度起動してください。

    [AGENT_EXITED]

    에이전트가 시작된 뒤 예기치 않게 멈췄습니다.The agent started and then stopped unexpectedly.エージェントは起動した後、予期せず停止しました。

    "상태 다시 확인"을 누르십시오. 안 되면 앱을 재시작하십시오.Click Check status again to see if it came back on its own. If not, quit the app and reopen it.「状態を再確認」を押して、自動で復帰したか確認してください。復帰しない場合は、アプリを終了してもう一度開いてください。

    [STOP_UNCONFIRMED]

    에이전트 종료를 확인하지 못했습니다. 아직 실행 중일 수 있습니다.The agent was asked to stop and did not confirm it had -- it may still be running.エージェントに停止を依頼しましたが、停止したという確認がありません。まだ動いている可能性があります。

    앱을 종료했다가 다시 여십시오.Quit the app and reopen it. That clears the old process for certain.アプリを終了してもう一度開いてください。

    [DISCORD_TOKEN_BAD]

    Discord 토큰이 없거나 거부됐습니다.The Discord bot token is missing or was rejected.Discordボットのトークンがないか、拒否されました。

    Discord 토큰을 다시 입력하십시오.Go back to the token step and paste a new token.トークンのステップに戻って、新しいトークンを貼り付けてください。

    [SLACK_TOKEN_BAD]

    Slack 토큰이 없거나 거부됐습니다.A Slack token is missing or was rejected. Slack uses two -- a bot token and an app-level token -- and either one can be the problem.Slackのボットトークンまたはアプリレベルトークンがないか、拒否されました。

    채널 탭에서 Slack 토큰 두 개를 다시 확인하십시오.Re-check both Slack tokens in Channels, then quit and reopen the app.チャンネルでSlackのトークン2つをもう一度確認してから、アプリを終了してもう一度開いてください。

    [TELEGRAM_TOKEN_BAD]

    Telegram 토큰이 없거나 거부됐습니다.The Telegram bot token is missing or was rejected.Telegramボットのトークンがないか、拒否されました。

    채널 탭에서 BotFather 토큰을 재확인하십시오.Re-check the token from BotFather in Channels, then quit and reopen the app.チャンネルでBotFatherから受け取ったトークンをもう一度確認してから、アプリを終了してもう一度開いてください。

    [CHANNEL_TOKEN_ERROR]

    메신저 토큰을 자격 증명 저장소에서 읽어 오지 못했습니다.The stored chat-service token could not be read. This is the computer refusing to unseal it -- the token itself may be perfectly good.保存されているチャットサービスのトークンを読み取れませんでした。

    채널 탭에서 토큰을 다시 저장하십시오.Quit the app and reopen it, and allow the credential prompt if one appears. If it keeps happening, re-save the token in Channels.アプリを終了してもう一度開き、認証情報の確認が表示されたら許可してください。それでも続く場合は、チャンネルでトークンを保存し直してください。

    [UNKNOWN]

    에이전트 시작에 실패했습니다.The agent failed to start.エージェントの起動に失敗しました。

    잠시 후 상태를 다시 확인하십시오.Wait a moment and click Check status again. If it keeps happening, quit the app and reopen it.しばらく待ってから「状態を再確認」を押してください。それでも続く場合は、アプリを終了してもう一度開いてください。

    마지막 답변 실패When the last reply fails最後の返信が失敗したとき

    [RATE_LIMIT]

    모델 서비스 사용량·속도 한도에 도달했습니다.The model service says a usage or rate limit was reached.モデルサービスの利用上限または速度制限に達しました。

    잠시 후 다시 보내십시오. 필요하면 다른 모델을 선택하십시오.Wait a little and send again; pick another model if needed.しばらく待ってからもう一度送信してください。必要なら別のモデルを選んでください。

    [AUTH]

    모델 연결 로그인이 만료됐거나 거부됐습니다.The model connection's login is expired or rejected.モデル接続のログインが期限切れ、または拒否されました。

    재로그인하십시오.Log in again.もう一度ログインしてください。

    [SERVER]

    모델 서비스가 과부하이거나 서버 오류를 반환합니다.The model service is overloaded or returning server errors.モデルサービスが混雑しているか、サーバーエラーを返しています。

    잠시 후 재시도하십시오.Try again in a little while.しばらくしてからもう一度送信してください。

    [TIMEOUT]

    모델이 제때 응답하지 않았습니다.The model did not answer in time.モデルが時間内に応答しませんでした。

    다시 보내십시오. 반복되면 다른 모델을 선택하십시오.Send again; pick another model if it repeats.もう一度送信してください。続く場合は別のモデルを選んでください。

    [AGY_TURN_ERROR]

    Antigravity 모델 호출에 실패했습니다.The Antigravity model call failed.Antigravity のモデル呼び出しに失敗しました。

    다시 보내십시오. 반복되면 모델 및 프로바이더 탭에서 다른 모델을 선택하십시오.Send again; if it repeats, pick another model in the Model & Providers tab.もう一度送信してください。続く場合は「モデルとプロバイダー」タブで別のモデルを選んでください。

    [PI_AI_ERROR]

    프로바이더가 호출을 거부했거나 실패했습니다.The provider refused or failed the call.プロバイダーがリクエストを拒否したか、呼び出しに失敗しました。

    요청을 바꿔 다시 보내십시오. 반복되면 프로바이더 상태를 확인하십시오.Send a different request; if it repeats, check the provider's status.リクエストを変えてもう一度送信してください。続く場合はプロバイダーの状態を確認してください。

    [INVALID_REQUEST]

    프로바이더가 요청을 거부했습니다(예: 텍스트 전용 모델에 이미지 전송).The provider rejected the request (for example, an image on a text-only model).プロバイダーがリクエストを拒否しました。テキスト専用モデルに画像を送った場合などです。

    입력을 바꿔 다시 보내십시오.Change the input and send again.入力を変えてもう一度送信してください。
