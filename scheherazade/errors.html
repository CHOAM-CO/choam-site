    세헤라자드 빨간 막대의 오류는 대괄호 안의 코드로 시작합니다. 아래에서 같은 코드의 의미와 조치를 확인하십시오.Every error in Scheherazade's red bar begins with a code in square brackets. Find the same code below to see what happened and what to do next.Scheherazade の赤いバーに表示されるエラーは、必ず角かっこで囲まれたコードから始まります。下の一覧で同じコードを探すと、何が起きたのかと、どうすればよいかを確認できます。

    에이전트 시작 실패와 중단When the agent doesn't start or stopsエージェントが起動しない・止まったとき

    [CLI_LOGIN_EXPIRED]

    Claude Code 로그인이 만료됐습니다.Claude Code login expired.Claude Code のログインの有効期限が切れています。

    터미널에서 claude를 한 번 실행해 로그인을 갱신하거나 모델 및 프로바이더 탭에서 다시 로그인하십시오.Run claude once in a terminal to refresh it, or log in again from the Model & Providers tab.ターミナルで claude を一度実行してログインを更新するか、「モデルとプロバイダー」タブからもう一度ログインしてください。

    [CLI_LOGIN_MISSING]

    이 컴퓨터에서 Claude Code 로그인 정보를 찾지 못했습니다.No Claude Code login was found on this machine.このパソコンに Claude Code のログイン情報が見つかりませんでした。

    모델 및 프로바이더 탭에서 로그인하거나 터미널에서 claude를 한 번 실행하십시오.Log in from the Model & Providers tab, or run claude once in a terminal.「モデルとプロバイダー」タブからログインするか、ターミナルで claude を一度実行してください。

    [CLI_CREDENTIALS_UNREADABLE]

    Claude Code 로그인 정보를 읽지 못했습니다.The Claude Code login could not be read.Claude Code のログイン情報を読み取れませんでした。

    다시 시도하십시오. 계속 실패하면 모델 및 프로바이더 탭에서 다시 로그인하십시오.Try again. If it keeps failing, log in again from the Model & Providers tab.もう一度お試しください。失敗が続く場合は、「モデルとプロバイダー」タブからもう一度ログインしてください。

    [CREDENTIALS_MISSING]

    선택한 모델 연결 키가 없습니다.The key for the selected model connection is missing.選択したモデル接続のキーが保存されていません。

    모델 및 프로바이더 탭에서 입력하십시오.Enter it in the Model & Providers tab.「モデルとプロバイダー」タブでキーを入力してください。

    [MODEL_MISSING]

    이 연결에 선택된 모델이 없습니다.No model is selected for this connection.この接続にはモデルが選択されていません。

    모델 및 프로바이더 탭에서 모델을 선택하십시오.Pick one in the Model & Providers tab.「モデルとプロバイダー」タブでモデルを選んでください。

    [CONFIG_INCOMPLETE]

    프록시 주소가 없습니다.The proxy address is missing.プロキシアドレスが設定されていません。

    모델 및 프로바이더 탭에서 Base URL을 입력하십시오.Enter the Base URL in the Model & Providers tab.「モデルとプロバイダー」タブで Base URL を入力してください。

    [LANE_UNAVAILABLE]

    연결된 서비스를 사용할 수 없었습니다.A connected service could not be used.接続されたサービスを使用できませんでした。

    모델 및 프로바이더 탭에서 해당 키와 모델을 다시 확인하십시오.Recheck its key and model in the Model & Providers tab.「モデルとプロバイダー」タブで該当のキーとモデルを再確認してください。

    [TIMEOUT_BOOT_STAGE]

    엔진 시작 전에 부팅이 멈췄습니다.The boot stalled before the engine started.エンジンが立ち上がる前に起動が止まりました。

    로그를 여십시오. 앱을 다시 시작하고 반복되면 엔진 설정을 확인하십시오.Open Logs. Restart the app; if it repeats, check the engine settings.ログを開いてください。アプリを再起動し、繰り返される場合はエンジン設定を確認してください。

    [TIMEOUT_ENGINE_SPAWN]

    엔진이 제시간에 시작되지 않았습니다.The engine did not start in time.エンジンが時間内に起動しませんでした。

    로그를 여십시오. 앱을 다시 시작하고 반복되면 다른 모델이나 프로바이더를 선택하십시오.Open Logs. Restart the app; if it repeats, pick another model or provider.ログを開いてください。アプリを再起動し、繰り返される場合は別のモデルまたはプロバイダーを選んでください。

    [TIMEOUT_NO_HEARTBEAT]

    에이전트가 부팅됐으나 연결되지 않았습니다.The agent booted but never connected.エージェントは起動しましたが、接続されませんでした。

    로그를 여십시오. 앱을 다시 시작하고 반복되면 채널 연결을 확인하십시오.Open Logs. Restart the app; if it repeats, check the channel connection.ログを開いてください。アプリを再起動し、繰り返される場合はチャンネル接続を確認してください。

    [TIMEOUT]

    에이전트가 시작됐는지 확인할 수 없습니다.Can't confirm whether the agent started.エージェントが起動したかどうかを確認できません。

    잠시 기다린 뒤 상태 다시 확인을 다시 클릭하십시오.Wait a moment, then click Check status again.少し待ってから、「状態を再確認」をもう一度クリックしてください。

    [KEY_ERROR]

    저장된 키를 읽지 못했습니다.Couldn't read the stored key.保存されたキーを読み取れませんでした。

    앱을 종료했다가 다시 여십시오. 반복되면 설정할 때 입력한 값을 확인하십시오.Quit the app and reopen it. If it keeps happening, double-check the values you entered at setup.アプリを終了してから開き直してください。繰り返される場合は、セットアップ時に入力した値をもう一度確認してください。

    [LOGIN_REQUIRED]

    이 모델 연결에는 로그인이 필요합니다.This model connection needs you to log in.このモデル接続にはログインが必要です。

    엔진 페이지에서 로그인하십시오. 로그인하면 에이전트가 자동으로 시작합니다.Log in on the Engine page. The agent starts by itself once you are signed in.「エンジンページ」でログインしてください。ログインすると、エージェントが自動で開始します。

    [PROVIDER_NOT_WIRED]

    선택한 모델 연결이 아직 준비되지 않았습니다.The model connection you chose isn't ready yet.選択したモデル接続はまだ準備ができていません。

    엔진 페이지에서 모델을 Claude로 전환한 뒤, 앱을 종료했다가 다시 여십시오.Switch the model to Claude on the Engine page, then quit and reopen the app.「エンジンページ」でモデルを Claude に切り替え、アプリを終了してから開き直してください。

    [MODEL_SELECTION_FAILED]

    선택한 모델 또는 effort가 거부됐습니다.The selected model or effort was rejected.選択したモデルまたは effort が拒否されました。

    엔진 페이지의 모델 선택기에서 다른 모델 또는 effort를 고르십시오.Pick a different model or effort in the model picker on the Engine page.「エンジンページ」のモデル選択欄で別のモデルまたは effort を選んでください。

    [CLI_MISSING]

    Antigravity CLI를 설치하지 못했습니다.The Antigravity CLI could not be installed.Antigravity CLI をインストールできませんでした。

    인터넷 연결을 확인한 뒤 앱을 종료했다가 다시 여십시오.Check your internet connection, then quit the app and reopen it.インターネット接続を確認してから、アプリを終了して開き直してください。

    [PROXY_UNAVAILABLE]

    이 모델 연결에 필요한 로컬 프록시가 실행되지 않아, 확인되지 않은 경로로 연결하는 대신 에이전트를 시작하지 않았습니다.The local proxy this model connection needs did not come up, and the agent was not started rather than routed somewhere unverified.このモデル接続に必要なローカルプロキシが立ち上がらなかったため、未確認の接続先にルーティングするのではなく、エージェントを起動しませんでした。

    앱을 종료했다가 다시 여십시오. 계속 발생하면 엔진 페이지에서 모델 연결을 변경하십시오.Quit the app and reopen it. If it keeps happening, switch the model connection on the Engine page.アプリを終了して開き直してください。繰り返し発生する場合は、「エンジンページ」でモデル接続を切り替えてください。

    [OLLAMA_UNAVAILABLE]

    로컬 Ollama 데몬이 실행 중이 아니므로 에이전트가 통신할 대상이 없습니다.The local Ollama daemon is not running, so there is nothing for the agent to talk to.ローカルの Ollama デーモンが起動していないため、エージェントの通信先がありません。

    Ollama를 시작하고 선택한 모델이 다운로드되어 있는지(ollama list) 확인한 뒤, 이 앱을 종료했다가 다시 여십시오.Start Ollama, confirm the model you picked is pulled (ollama list), then quit this app and reopen it.Ollama を起動し、選択したモデルが取得済みか（ollama list）確認してから、このアプリを終了してから開き直してください。

    [APP_FILES_MISSING]

    에이전트 자체 설치 파일 일부가 누락됐습니다.Part of the agent's own installation is missing.エージェント本体のインストールの一部が欠けています。

    앱을 다시 설치하십시오. 입력한 내용은 사라지지 않으며, 설정과 메모리는 앱 외부에 저장됩니다.Reinstall the app. Nothing you entered is lost -- your settings and memory live outside the app.アプリを再インストールしてください。入力した内容は失われず、設定とメモリはアプリの外に保存されています。

    [HARNESS_STALE]

    에이전트의 지침 파일을 이 버전에 맞게 업데이트하지 못했습니다.The agent's instruction files couldn't be updated for this version.エージェントの指示ファイルをこのバージョン用に更新できませんでした。

    앱을 종료했다가 다시 여십시오. 다시 열면 업데이트를 재시도하고, 성공하면 에이전트가 다시 시작합니다.Quit the app and reopen it. Reopening retries the update, and the agent starts again once it succeeds.アプリを終了してから開き直してください。開き直すと更新が再試行され、成功するとエージェントが再び開始します。

    [APP_WRITTEN_DAMAGED]

    편집한 파일 기록이 손상됐습니다.The record of your edited files is damaged.編集したファイルの記録が破損しています。

    기록을 초기화하십시오. 편집 내용은 그대로 유지됩니다.Reset it. Your edits stay.記録をリセットしてください。編集内容はそのまま残ります。

    [HARNESS_ERROR]

    에이전트의 위임 지침을 업데이트하지 못했습니다.The agent's delegation instructions couldn't be updated.エージェントの委任指示を更新できませんでした。

    다시 시도하려면 앱을 종료했다가 다시 여십시오. 여전히 실패하면 로그를 여십시오.Quit the app and reopen it to retry. If it still fails, open Logs.再試行するには、アプリを終了してから開き直してください。それでも失敗する場合は、ログを開いてください。

    [SPAWN_FAILED]

    에이전트를 전혀 시작하지 못했습니다.The agent could not be started at all.エージェントをまったく起動できませんでした。

    앱을 종료했다가 다시 여십시오. 계속 발생하면 앱을 다시 설치하십시오.Quit the app and reopen it. If it keeps happening, reinstall the app.アプリを終了して開き直してください。繰り返し発生する場合は、アプリを再インストールしてください。

    [CRASH_LOOP]

    에이전트 프로세스가 반복해서 종료됩니다. 정확한 원인은 확인되지 않았습니다.The agent's process keeps exiting repeatedly. The exact cause isn't confirmed.エージェントのプロセスが繰り返し終了しています。正確な原因は確認されていません。

    앱을 종료했다가 다시 여십시오. 반복되면 설정할 때 입력한 값을 다시 확인하십시오.Quit the app and reopen it. If it keeps happening, double-check the values you entered at setup.アプリを終了してから開き直してください。繰り返される場合は、設定時に入力した値をもう一度確認してください。

    [ENGINE_START_FAILED]

    엔진 시작에 실패했습니다.The engine failed to start.エンジンの起動に失敗しました。

    엔진 페이지에서 다른 모델을 고르거나 프로바이더를 끄고 에이전트를 다시 시작하십시오.On the Engine page, pick another model or turn a provider off, then start the agent again.「エンジンページ」で別のモデルを選ぶか、プロバイダーをオフにしてから、エージェントをもう一度開始してください。

    [AGENT_EXITED]

    에이전트가 시작된 뒤 예기치 않게 중단됐습니다.The agent started and then stopped unexpectedly.エージェントが起動した後、予期せず停止しました。

    상태 다시 확인을 한 번 더 클릭해 저절로 복구됐는지 확인하십시오. 그렇지 않으면 앱을 종료했다가 다시 여십시오.Click Check status again to see if it came back on its own. If not, quit the app and reopen it.「状態を再確認」をもう一度クリックして、自動で復旧したか確認してください。復旧しない場合は、アプリを終了してから開き直してください。

    [STOP_UNCONFIRMED]

    에이전트에 종료를 요청했으나 확인되지 않아 아직 실행 중일 수 있습니다.The agent was asked to stop and did not confirm it had -- it may still be running.エージェントに停止を指示しましたが確認が取れなかったため、まだ実行中の可能性があります。

    앱을 종료했다가 다시 여십시오. 그러면 이전 프로세스가 확실히 정리됩니다.Quit the app and reopen it. That clears the old process for certain.アプリを終了して開き直してください。これにより、以前のプロセスを確実に終了できます。

    [DISCORD_TOKEN_BAD]

    Discord 봇 토큰이 없거나 거부됐습니다.The Discord bot token is missing or was rejected.Discord のボットトークンがないか、拒否されました。

    토큰 단계로 돌아가 새 토큰을 붙여넣으십시오.Go back to the token step and paste a new token.トークンのステップに戻り、新しいトークンを貼り付けてください。

    [SLACK_TOKEN_BAD]

    Slack 토큰이 없거나 거부됐으며, Slack이 사용하는 봇 토큰과 앱 수준 토큰 두 가지 중 어느 쪽이든 문제일 수 있습니다.A Slack token is missing or was rejected. Slack uses two -- a bot token and an app-level token -- and either one can be the problem.Slack のトークンが設定されていないか拒否されており、Slack が使用するボットトークンとアプリレベルトークンの2つのうち、どちらかに問題がある可能性があります。

    채널 탭에서 두 Slack 토큰을 다시 확인한 뒤 앱을 종료했다가 다시 여십시오.Re-check both Slack tokens in Channels, then quit and reopen the app.チャンネルで両方の Slack トークンを再確認してから、アプリを終了して開き直してください。

    [TELEGRAM_TOKEN_BAD]

    Telegram 봇 토큰이 없거나 거부됐습니다.The Telegram bot token is missing or was rejected.Telegram のボットトークンが設定されていないか拒否されました。

    채널 탭에서 BotFather로부터 받은 토큰을 다시 확인한 뒤 앱을 종료했다가 다시 여십시오.Re-check the token from BotFather in Channels, then quit and reopen the app.チャンネルで BotFather から取得したトークンを再確認してから、アプリを終了して開き直してください。

    [CHANNEL_TOKEN_ERROR]

    저장된 채팅 서비스 토큰을 읽지 못했습니다. 컴퓨터가 잠금 해제를 거부한 것이며, 토큰 자체는 정상일 수 있습니다.The stored chat-service token could not be read. This is the computer refusing to unseal it -- the token itself may be perfectly good.保存されているチャットサービスのトークンを読み取れませんでした。コンピューターがロック解除を拒否しているためで、トークン自体は問題ない可能性があります。

    앱을 종료했다가 다시 열고, 자격 증명 요청 창이 나타나면 허용하십시오. 반복되면 채널 탭에서 토큰을 다시 저장하십시오.Quit the app and reopen it, and allow the credential prompt if one appears. If it keeps happening, re-save the token in Channels.アプリを終了してから開き直し、資格情報の確認画面が表示されたら許可してください。繰り返される場合は、チャンネルでトークンを保存し直してください。

    [UNKNOWN]

    에이전트 시작에 실패했습니다.The agent failed to start.エージェントの起動に失敗しました。

    잠시 기다린 뒤 상태 다시 확인을 다시 클릭하십시오. 계속 발생하면 앱을 종료했다가 다시 여십시오.Wait a moment and click Check status again. If it keeps happening, quit the app and reopen it.少し待ってから、「状態を再確認」をもう一度クリックしてください。繰り返し発生する場合は、アプリを終了して開き直してください。

    [AUTH]
