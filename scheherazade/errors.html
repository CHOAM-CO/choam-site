    오류 코드Error codesエラーコード

    세헤라자드 빨간 막대의 오류는 대괄호 안의 코드로 시작합니다. 아래에서 같은 코드의 의미와 조치를 확인하십시오.Every error in Scheherazade's red bar begins with a code in square brackets. Find the same code below to see what happened and what to do next.Scheherazade の赤いバーに表示されるエラーは、必ず角かっこで囲まれたコードから始まります。下の一覧で同じコードを探すと、何が起きたのかと、どうすればよいかを確認できます。

    에이전트 시작 실패와 중단When the agent doesn't start or stopsエージェントが起動しない・止まったとき

    [CLI_LOGIN_EXPIRED]

    Claude Code 로그인이 만료됐습니다.The Claude Code login saved on this computer has expired.このパソコンに保存されている Claude Code のログインの有効期限が切れています。

    터미널에서 claude를 한 번 실행하거나 모델 및 프로바이더 탭에서 다시 로그인하십시오.Run claude once in a terminal to refresh the login, or log in again from the Model & Providers tab.ターミナルで claude を一度実行してログインを更新するか、「モデルとプロバイダー」タブからもう一度ログインしてください。

    [CLI_LOGIN_MISSING]

    컴퓨터에 Claude Code 로그인이 없습니다.This computer has no Claude Code login.このパソコンには Claude Code のログイン情報がありません。

    모델 및 프로바이더 탭에서 로그인하거나 터미널에서 claude를 한 번 실행하십시오.Log in from the Model & Providers tab, or run claude once in a terminal.「モデルとプロバイダー」タブからログインするか、ターミナルで claude を一度実行してください。

    [CLI_CREDENTIALS_UNREADABLE]

    Claude Code 로그인 정보를 읽지 못했습니다.A Claude Code login exists, but the app could not read it.Claude Code のログイン情報はありますが、アプリが読み取れませんでした。

    다시 시도하십시오. 계속 실패하면 모델 및 프로바이더 탭에서 다시 로그인하십시오.Try once more. If the same error keeps appearing, log in again from the Model & Providers tab.もう一度お試しください。同じエラーが繰り返される場合は、「モデルとプロバイダー」タブからログインし直してください。

    [CREDENTIALS_MISSING]

    선택한 모델 연결 키가 없습니다.The key or token for the selected model connection has not been saved.選択したモデル接続に必要なキーまたはトークンが保存されていません。

    모델 및 프로바이더 탭에서 입력하십시오.Enter the key or token in the Model & Providers tab.「モデルとプロバイダー」タブでキーまたはトークンを入力してください。

    [MODEL_MISSING]

    이 연결에 선택된 모델이 없습니다.No model is selected for the chosen model connection.選択したモデル接続で使うモデルが指定されていません。

    모델 및 프로바이더 탭에서 선택하십시오.Choose a model in the Model & Providers tab.「モデルとプロバイダー」タブで使うモデルを選んでください。

    [CONFIG_INCOMPLETE]

    프록시 주소가 없습니다.The proxy address (Base URL) for the custom connection is empty.カスタム接続のアドレス（Base URL）が空欄になっています。

    모델 및 프로바이더 탭에 Base URL을 입력하십시오.Enter the Base URL in the Model & Providers tab.「モデルとプロバイダー」タブで Base URL を入力してください。

    [LANE_UNAVAILABLE]

    연결 서비스를 쓸 수 없습니다.A service you connected cannot be used with the key, model or address saved for it.接続したサービスは、保存されているキー・モデル・アドレスでは使用できません。

    모델 및 프로바이더 탭에서 키와 모델을 확인하십시오.Check that service's key and model again in the Model & Providers tab.「モデルとプロバイダー」タブで、そのサービスのキーとモデルを確認してください。

    [TIMEOUT_BOOT_STAGE]

    엔진 시작 전에 부팅이 멈췄습니다.Startup stalled before the engine came up.エンジンが立ち上がる前の段階で起動が止まりました。

    로그를 확인하십시오. 앱을 다시 시작하고 반복되면 엔진 설정을 확인하십시오.Open Logs first, then restart the app. If it happens again, check the engine settings.まずログを確認し、アプリを再起動してください。同じエラーが繰り返される場合は、エンジン設定を確認してください。

    [TIMEOUT_ENGINE_SPAWN]

    엔진이 제때 뜨지 않았습니다.The agent process started, but the engine did not come up in time.エージェントのプロセスは起動しましたが、エンジンが時間内に立ち上がりませんでした。

    로그를 확인하십시오. 앱을 다시 시작하고 반복되면 다른 모델을 선택하십시오.Open Logs first, then restart the app. If it happens again, choose another model or provider.まずログを確認し、アプリを再起動してください。同じエラーが繰り返される場合は、別のモデルかプロバイダーを選んでください。

    [TIMEOUT_NO_HEARTBEAT]

    에이전트는 떴지만 연결되지 않았습니다.Startup finished, but the agent never reported that it was connected.起動処理は終わりましたが、エージェントから接続完了の知らせが届きませんでした。

    로그를 확인하십시오. 앱을 다시 시작하고 반복되면 채널 연결을 확인하십시오.Open Logs first, then restart the app. If it happens again, check the channel connection.まずログを確認し、アプリを再起動してください。同じエラーが繰り返される場合は、チャンネルの接続を確認してください。

    [TIMEOUT]

    에이전트 시작 여부를 확인하지 못했습니다.Startup took too long, and the app cannot tell which stage it stopped at.起動に時間がかかりすぎました。どの段階で止まったのかは、アプリでは特定できません。

    잠시 후 "상태 다시 확인"을 누르십시오.Open Logs and check what happened.ログを開いて確認してください。

    [KEY_ERROR]

    저장된 키를 읽지 못했습니다.The saved provider key could not be read from your operating system's credential store.保存したプロバイダーのキーを、OS の資格情報ストアから読み取れませんでした。

    앱을 종료했다가 다시 여십시오. 반복되면 설정할 때 입력한 값을 확인하십시오.Save the key again in the Model & Providers tab.「モデルとプロバイダー」タブでキーを保存し直してください。

    [LOGIN_REQUIRED]

    이 모델은 로그인해야 합니다.This model connection needs a sign-in that has not been completed yet.このモデル接続にはログインが必要ですが、まだ完了していません。

    모델 및 프로바이더 탭에서 로그인하십시오. 로그인하면 에이전트가 자동으로 시작됩니다.Log in from the Model & Providers tab. Once you are signed in, the agent starts on its own.「モデルとプロバイダー」タブからログインしてください。ログインが済むと、エージェントは自動で起動します。

    [PROVIDER_NOT_WIRED]

    선택한 모델 연결이 준비되지 않았습니다.The app does not recognize the saved provider name, or that provider's setup is invalid.保存されたプロバイダー名をアプリが認識できないか、そのプロバイダーの設定が正しくありません。

    모델 및 프로바이더 탭에서 Claude로 바꾸십시오.Choose the provider again in the Model & Providers tab.「モデルとプロバイダー」タブでプロバイダーを選び直してください。

    [MODEL_SELECTION_FAILED]

    고른 모델이나 effort가 거부됐습니다.The selected model or effort level was rejected.選択したモデルまたは推論の強さが受け付けられませんでした。

    모델 및 프로바이더 탭에서 다른 모델·effort를 고르십시오.Choose a different model or effort level in the Model & Providers tab.「モデルとプロバイダー」タブで別のモデルか推論の強さを選んでください。

    [CLI_MISSING]

    Antigravity CLI 설치에 실패했습니다.The Antigravity command-line tool could not be installed.Antigravity のコマンドラインツールをインストールできませんでした。

    인터넷 연결을 확인하고 앱을 재시작하십시오.Check your internet connection, then reopen the app.インターネット接続を確認してから、アプリを開き直してください。

    [PROXY_UNAVAILABLE]

    이 모델 연결의 로컬 프록시가 실행되지 않았습니다.The local proxy that the selected connection needs did not start.選択した接続に必要なローカルプロキシが起動しませんでした。

    앱을 다시 시작하십시오. 반복되면 모델 및 프로바이더 탭에서 연결을 바꾸십시오.Restart the app. If it happens again, choose another provider.アプリを再起動してください。同じエラーが繰り返される場合は、別のプロバイダーを選んでください。

    [OLLAMA_UNAVAILABLE]

    로컬 Ollama 데몬이 실행 중이 아닙니다.The local Ollama service is not running.ローカルの Ollama サービスが起動していません。

    Ollama를 실행하고 ollama list로 모델을 확인한 뒤 앱을 다시 여십시오.Start Ollama first, then restart the agent.先に Ollama を起動してから、エージェントをもう一度開始してください。

    [APP_FILES_MISSING]

    에이전트 설치 파일 일부가 없습니다.A file that ships with the app is missing from the installation.アプリに同梱されているはずのファイルが1つ、インストール先に見当たりません。

    앱을 재설치하십시오.Reinstall the app.アプリをインストールし直してください。

    [HARNESS_STALE]

    에이전트 지침 파일을 이 버전에 맞게 갱신하지 못했습니다.The agent's instruction files could not be updated for this version.エージェントの指示ファイルを、このバージョンに合わせて更新できませんでした。

    앱을 재시작하십시오. 다시 열면 업데이트를 재시도합니다.Reopen the app. Reopening it tries the update again.アプリを開き直してください。開き直すと、更新をもう一度試みます。

    [APP_WRITTEN_DAMAGED]

    수정 파일 기록이 손상됐습니다.The record of the files you edited yourself is damaged.ご自身で編集したファイルの記録が壊れています。

    재설정하십시오. 수정한 내용은 그대로 남습니다.Reset it. Your edits stay as they are.リセットしてください。リセットしても、編集した内容はそのまま残ります。

    [HARNESS_ERROR]

    에이전트 위임 지침 갱신에 실패했습니다.The agent's delegation instructions could not be updated.エージェントの委任に関する指示を更新できませんでした。

    앱을 다시 여십시오. 계속 실패하면 로그를 확인하십시오.Reopen the app. If it happens again, open Logs.アプリを開き直してください。同じエラーが繰り返される場合は、ログを確認してください。

    [SPAWN_FAILED]

    에이전트를 시작하지 못했습니다.The agent process could not be started at all.エージェントのプロセスをまったく起動できませんでした。

    앱을 다시 시작하십시오. 반복되면 앱을 재설치하십시오.Restart the app. If it happens again, open Logs.アプリを再起動してください。同じエラーが繰り返される場合は、ログを確認してください。

    [CRASH_LOOP]

    에이전트 프로세스가 반복 종료됩니다.The agent process keeps exiting shortly after it starts.エージェントのプロセスが、起動直後に終了することを繰り返しています。

    앱을 종료했다가 다시 여십시오. 반복되면 설정할 때 입력한 값을 다시 확인하십시오.Quit the app and open it again. If it happens again, check the values you entered during setup.アプリを終了してから開き直してください。同じエラーが繰り返される場合は、設定時に入力した値を確認してください。

    [ENGINE_START_FAILED]

    엔진 시작에 실패했습니다.The agent kept exiting right after it started, and the engine recorded its own startup error.起動直後の終了が続けて起こり、エンジン自身が起動エラーを記録しました。

    모델 및 프로바이더 탭에서 다른 모델을 고르거나 프로바이더를 끄고 재시작하십시오.Choose another model or turn a provider off in the Model & Providers tab, then start again.「モデルとプロバイダー」タブで別のモデルを選ぶか、プロバイダーをオフにしてから、もう一度開始してください。

    [AGENT_EXITED]

    에이전트가 시작된 뒤 예기치 않게 멈췄습니다.The agent process started and then exited on its own.エージェントのプロセスが起動したあと、自ら終了しました。

    "상태 다시 확인"을 누르십시오. 안 되면 앱을 재시작하십시오.Start the agent again. If it exits again, open Logs.エージェントをもう一度開始してください。同じエラーが繰り返される場合は、ログを確認してください。

    [STOP_UNCONFIRMED]

    에이전트 종료를 확인하지 못했습니다. 아직 실행 중일 수 있습니다.During a stop or restart, the app could not confirm that the old process had fully ended.停止または再起動の際に、以前のプロセスが完全に終わったかどうかを確認できませんでした。

    앱을 종료했다가 다시 여십시오.Wait a moment, then try again.少し待ってから、もう一度お試しください。

    [DISCORD_TOKEN_BAD]

    Discord 토큰이 없거나 거부됐습니다.The Discord bot token is missing or was rejected.Discord のボットトークンがないか、受け付けられませんでした。

    Discord 토큰을 다시 입력하십시오.Reconnect Discord in Channels.チャンネルで Discord を接続し直してください。

    [SLACK_TOKEN_BAD]

    Slack 토큰이 없거나 거부됐습니다.A Slack token is missing or was rejected.Slack のトークンがないか、受け付けられませんでした。

    채널 탭에서 Slack 토큰 두 개를 다시 확인하십시오.Check both Slack tokens again in Channels.チャンネルで Slack のトークン2つをどちらも確認してください。

    [TELEGRAM_TOKEN_BAD]

    Telegram 토큰이 없거나 거부됐습니다.The Telegram bot token is missing or was rejected.Telegram のボットトークンがないか、受け付けられませんでした。

    채널 탭에서 BotFather 토큰을 재확인하십시오.Check the Telegram token again in Channels.チャンネルで Telegram のトークンを確認してください。

    [CHANNEL_TOKEN_ERROR]

    메신저 토큰을 자격 증명 저장소에서 읽어 오지 못했습니다.A messenger token could not be read from the credential store.メッセンジャーのトークンを資格情報ストアから読み取れませんでした。

    채널 탭에서 토큰을 다시 저장하십시오.Reconnect that messenger in Channels.チャンネルでそのメッセンジャーを接続し直してください。

    [UNKNOWN]

    에이전트 시작에 실패했습니다.Something failed, and the app cannot identify the cause.何らかの処理が失敗しましたが、アプリでは原因を特定できませんでした。

    잠시 후 상태를 다시 확인하십시오.Wait a moment, then check the status again.少し待ってから、状態をもう一度確認してください。

    마지막 답변 실패When the last reply fails最後の返信が失敗したとき

    [RATE_LIMIT]

    모델 서비스 사용량·속도 한도에 도달했습니다.The model service reports that a usage or rate limit has been reached.モデルサービスから、利用量またはレートの上限に達したとの通知がありました。

    잠시 후 다시 보내십시오. 필요하면 다른 모델을 선택하십시오.Wait a little, then send again. Choose another model if needed.少し待ってから送り直してください。必要に応じて別のモデルを選んでください。

    [AUTH]

    모델 연결 로그인이 만료됐거나 거부됐습니다.The login for the model connection has expired or was rejected.モデル接続のログインが切れているか、拒否されました。

    재로그인하십시오.Log in again.もう一度ログインしてください。

    [SERVER]

    모델 서비스가 과부하이거나 서버 오류를 반환합니다.The model service is overloaded or returning server errors.モデルサービスが混み合っているか、サーバーエラーを返しています。

    잠시 후 재시도하십시오.Wait a little while, then send again.少し時間をおいてから送り直してください。

    [TIMEOUT]

    모델이 제때 응답하지 않았습니다.The model did not respond in time.モデルが時間内に応答しませんでした。

    다시 보내십시오. 반복되면 다른 모델을 선택하십시오.Send again. If it keeps timing out, choose another model.もう一度送ってください。同じエラーが繰り返される場合は、別のモデルを選んでください。

    [AGY_TURN_ERROR]

    Antigravity 모델 호출에 실패했습니다.The call to the Antigravity model failed.Antigravity のモデル呼び出しが失敗しました。

    다시 보내십시오. 반복되면 모델 및 프로바이더 탭에서 다른 모델을 선택하십시오.Send again. If it happens again, choose another model in the Model & Providers tab.もう一度送ってください。同じエラーが繰り返される場合は、「モデルとプロバイダー」タブで別のモデルを選んでください。

    [PI_AI_ERROR]

    프로바이더가 호출을 거부했거나 실패했습니다.The provider refused the call, or the call failed.プロバイダーが呼び出しを拒否したか、呼び出しそのものが失敗しました。

    요청을 바꿔 다시 보내십시오. 반복되면 프로바이더 상태를 확인하십시오.Send a different request. If it happens again, check the provider's status.リクエストの内容を変えて送り直してください。同じエラーが繰り返される場合は、プロバイダーの稼働状況を確認してください。

    [INVALID_REQUEST]

    프로바이더가 요청을 거부했습니다(예: 텍스트 전용 모델에 이미지 전송).The provider rejected the request, for example because an image was sent to a text-only model.プロバイダーがリクエストを拒否しました。テキスト専用のモデルに画像を送った場合などが該当します。

    입력을 바꿔 다시 보내십시오.Change the input and send again.入力内容を変えて送り直してください。
