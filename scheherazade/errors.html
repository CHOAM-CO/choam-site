    [CLI_LOGIN_EXPIRED]

    이 컴퓨터에 저장된 Claude Code 로그인이 만료되었습니다.The Claude Code login saved on this computer has expired.このパソコンに保存されている Claude Code のログインの有効期限が切れています。

    터미널에서 claude를 한 번 실행해 로그인을 새로 고치거나, 설정 > 모델에서 다시 로그인하세요.Run claude once in a terminal to refresh the login, or log in again from Settings > Model.ターミナルで claude を一度実行してログインを更新するか、設定 > モデル からもう一度ログインしてください。

    [CLI_LOGIN_MISSING]

    이 컴퓨터에는 Claude Code 로그인 정보가 없습니다.This computer has no Claude Code login.このパソコンには Claude Code のログイン情報がありません。

    설정 > 모델에서 로그인하거나, 터미널에서 claude를 한 번 실행하세요.Log in from Settings > Model, or run claude once in a terminal.設定 > モデル からログインするか、ターミナルで claude を一度実行してください。

    [CLI_CREDENTIALS_UNREADABLE]

    Claude Code 로그인 정보는 있지만 앱이 읽어 들이지 못했습니다.A Claude Code login exists, but the app could not read it.Claude Code のログイン情報はありますが、アプリが読み取れませんでした。

    한 번 더 시도하세요. 같은 오류가 반복되면 설정 > 모델에서 다시 로그인하세요.Try once more. If the same error keeps appearing, log in again from Settings > Model.もう一度お試しください。同じエラーが繰り返される場合は、設定 > モデル からログインし直してください。

    [CREDENTIALS_MISSING]

    선택한 모델 연결에 필요한 키나 토큰이 저장되어 있지 않습니다.The key or token for the selected model connection has not been saved.選択したモデル接続に必要なキーまたはトークンが保存されていません。

    설정 > 모델에서 키나 토큰을 입력하세요.Enter the key or token in Settings > Model.設定 > モデル でキーまたはトークンを入力してください。

    [MODEL_MISSING]

    선택한 모델 연결에 사용할 모델이 지정되어 있지 않습니다.No model is selected for the chosen model connection.選択したモデル接続で使うモデルが指定されていません。

    설정 > 모델에서 사용할 모델을 선택하세요.Choose a model in Settings > Model.設定 > モデル で使うモデルを選んでください。

    [CONFIG_INCOMPLETE]

    사용자 지정 연결의 주소(Base URL)가 비어 있습니다.The proxy address (Base URL) for the custom connection is empty.カスタム接続のアドレス（Base URL）が空欄になっています。

    설정 > 모델에서 Base URL을 입력하세요.Enter the Base URL in Settings > Model.設定 > モデル で Base URL を入力してください。

    [LANE_UNAVAILABLE]

    먼저 로그를 확인하고 앱을 다시 시작하세요. 같은 오류가 반복되면 엔진 설정을 확인하세요.Open Logs first, then restart the app. If it happens again, check the engine settings.まずログを確認し、アプリを再起動してください。同じエラーが繰り返される場合は、エンジン設定を確認してください。
