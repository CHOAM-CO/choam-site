    602는 게임 클라이언트에 직접 링크하는 Story Engine Native SDK와, 별도 런타임 설치 없이 시나리오 작성·사전 검증·시뮬레이션을 수행하는 Standalone Story Editor 두 가지 독립 패키지로 배포됩니다. 아래 라이선스 및 오픈소스 고지 사항에 동의하면 아카이브를 받을 수 있습니다.

    602 ships as two standalone binary distributions: the Story Engine Native SDK for linking directly into your game runtime, and the Standalone Story Editor for authoring, static validation, and scene-jump simulation with zero external runtime setup. Review and accept the license agreement below to unlock the archives.

    602 は、ゲームクライアントへ直接リンクする Story Engine Native SDK と、外部ランタイム不要でシナリオ執筆・事前検証・場面ジャンプ再生を行える Standalone Story Editor の 2 つの独立パッケージとして配布されます。下のライセンス契約およびオープンソース告知に同意するとアーカイブを入手できます。

    v1.2.0 · C ABI v1 · CHOAM Community License 1.0

    story_engine.h C ABI 공유 라이브러리, 오프라인 컴파일러·검증기 storyc CLI, C++17·C#(Unity)·Godot 연동 예제 포함.

    story_engine.h C ABI shared library, offline storyc compiler/validator CLI, and C++17, C# (Unity), and Godot integration examples.

    story_engine.h C ABI 共有ライブラリ、オフライン検証・コンパイラ storyc CLI、C++17・C#（Unity）・Godot 連携サンプルを同梱。

    602 Story Editor

    v0.1.4 · Apache-2.0 · Bundled Engine v1.2.0

    비주얼 분기 그래프 에디터, 임의 장면 점프 시뮬레이터, 내장 story-agent 및 원격 MCP 서버(/mcp) 탑재. Python·Node 별도 설치 불필요.

    Visual branching graph editor, arbitrary scene-jump simulator, built-in story-agent, and Remote MCP server (/mcp). Zero Python or Node install required.

    ビジュアル分岐グラフエディタ、任意シーンからのジャンプ再生シミュレータ、内蔵 story-agent、Remote MCP サーバー（/mcp）を搭載。Python・Node の事前導入は不要。

    STEP 03 · VERIFY & FIRST RUN

    체크섬 검증 및 첫 실행 Checksum Verification & First Run チェックサム検証と初回実行

    압축 해제나 실행 전에 함께 받은 .sha256 파일로 무결성을 검증하세요. 공식 배포 경로는 choam.studio와 GitHub의 CHOAM-CO/602-releases뿐입니다.

    Verify archive integrity against the companion .sha256 file before extracting or running binaries. Official archives are published exclusively via choam.studio and CHOAM-CO/602-releases on GitHub.

    展開や実行の前に、同梱の .sha256 ファイルで整合性を検証してください。公式の配布元は choam.studio および GitHub の CHOAM-CO/602-releases のみです。

    1. SHA-256 무결성 검증 (macOS · Linux · Windows PowerShell) 1. Verify SHA-256 Checksums (macOS · Linux · Windows PowerShell) 1. SHA-256 チェックサムの検証 (macOS · Linux · Windows PowerShell) 

    # macOS
shasum -a 256 -c *.sha256

# Linux
sha256sum -c *.sha256

# Windows (PowerShell)
Get-FileHash .\story-engine-v1.2.0-windows-x64.zip -Algorithm SHA256

    2. macOS 격리 속성 해제 (Gatekeeper 안내가 뜰 때) 2. Clear macOS Quarantine Attribute (Unsigned Binary Gatekeeper Prompt) 2. macOS 隔離属性の解除（Gatekeeper 警告が表示された場合）

    체크섬이 일치하는 공식 아카이브임을 확인한 뒤, 압축을 푼 폴더에 한해 com.apple.quarantine 속성을 제거합니다.

    After confirming the SHA-256 hash matches the official release, clear com.apple.quarantine on the extracted archive directory.

    SHA-256 ハッシュが公式リリースと一致することを確認したうえで、展開先ディレクトリに対してのみ com.apple.quarantine 属性を解除します。

    unzip story-engine-v1.2.0-macos-arm64.zip -d story-engine-sdk
xattr -dr com.apple.quarantine ./story-engine-sdk

    3. 동작 확인 (Story Engine CLI 및 Story Editor) 3. Smoke-Test the CLI & Standalone Editor 3. 動作確認（Story Engine CLI および Story Editor） 

    # Story Engine SDK — validate & inspect the bundled sample scenario
./bin/storyc check docs/examples/story.json

# Standalone Story Editor — verify embedded runtime version
./story-editor --version
